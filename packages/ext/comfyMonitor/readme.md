# ComfyUI 状态栏

画布顶部的可拖动状态栏，显示远端 ComfyUI 主机的显存、内存、队列，以及（安装采集脚本后）CPU 使用率、GPU 利用率、温度与功耗。

## 使用

1. 插件市场启用本扩展后，画布顶部出现状态栏。
2. 点齿轮 → 「添加目标」，填 `http://<IP>:<端口>`（例如 `http://192.168.2.6:8188`）。
3. 拖动左侧手柄移动位置，`▾` 折叠，齿轮里可勾选显示项与刷新间隔。

## 指标来源

- 默认（无需部署）：ComfyUI 自带 `/system_stats`、`/queue`，可读显存总量/可用、内存总量/可用、队列长度、ComfyUI 版本。此模式下 CPU 使用率、GPU 利用率、温度、功耗显示为「不可用」。
- 完整模式：把 `sidecar/toonflow_metrics.py` 复制到 ComfyUI 的 `custom_nodes/` 目录并重启 ComfyUI（或点状态栏设置里的「复制采集脚本」粘贴过去）。可选依赖 `psutil`、`pynvml`。

> ComfyUI 官方接口不提供 CPU 使用率与温度，这是上游限制，不是本插件省略。
