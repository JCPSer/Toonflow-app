# 图片节点

在画布中展示图片，可作为角色、场景、道具或分镜参考。

## 输入与输出

- 导入本地图片文件，单个文件不能为空且不超过 100 MB。
- 输出当前图片素材，可连接图片生成、视频生成等支持图片输入的节点。

## 使用方法

1. 点击上传按钮，选择图片文件。
2. 上传完成后，节点按图片比例显示预览。
3. 将图片输出连接到需要参考图的节点。
4. 选中节点后，使用顶部工具栏下载、预览或替换图片。

## 缩放

选中节点后点击顶部工具栏的「缩放」图标，在弹层中设置倍率（0.05–8）与长边上限（0–8192，0 表示不启用），保持宽高比，长边上限只缩不放。

- 目标尺寸与原图相同时不会重新编码。
- 目标面积超过 64 MP 时会在输入阶段提示并禁止应用。
- 应用后覆盖当前输出，原图文件保留；可使用一次「恢复缩放前」回退。
- 输出沿用 png/jpg/jpeg/webp 扩展名，gif/bmp/avif/tiff 等格式统一转为 PNG。
- 倍率与长边上限会记录在节点中，下次打开弹层沿用。
