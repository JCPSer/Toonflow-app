# Agent

画布中的 Agent 节点。它把上游内容作为上下文，在节点旁的对话面板中接收任务并直接操作画布，无需切换到右侧主对话。

## 输入与输出

- 左侧只有一个输入端口，支持文本、图片、视频、音频和文件。
- 节点没有输出端口，也不产生可连接的输出。
- 上游内容只作为上下文，不会自动触发运行；在对话面板中手动发送消息后才会执行。
- 对话本身由画布层的对话面板承载，节点只显示最近一轮提问摘要和上游输入统计。

## 角色

- 节点面板头部「Agent 角色」按钮可维护全局角色库：名称、描述（仅展示）、系统提示词。
- 选中角色的提示词排在软件默认提示之前：职责、语气与工作范围以角色为准；工具授权、算力确认、资料与凭据边界仍按软件规则执行。
- 角色只作用于画布 Agent 节点，保存在节点的 `agentRoleId`；派发任务时目标节点使用自己的角色，子 Agent 不继承。
- 切换角色只影响后续轮次，不改写已有会话；角色被删除或工作区分享后，节点回退「通用」。
