# 便签节点

在画布上写说明、待办和设定备忘的纯文本便签，不调用模型、不参与数据流。

## 特性

- 无端口、不可连线，只作为画布上的旁注存在。
- 双击正文进入编辑，Enter 换行，Esc 或点击空白处提交；编辑期间的键盘与滚轮只作用于便签。
- 选中节点后顶部出现配色栏：6 种背景色与 6 种字体色，可自由搭配。
- 四角手柄可拖拽调整大小（最小 160×160），内容超出时在便签内部滚动。
- 尺寸与配色可以随画布撤销/重做；正文内容单独由画布自动保存。

## 使用方法

1. 在画布右键菜单选择“便签”，或从节点面板添加。
2. 双击正文输入内容，退出编辑后内容随画布自动保存。
3. 选中节点，用顶部色块切换背景色与字体色。
4. 拖动四角手柄调整尺寸；按住 Shift 等画布常规操作不受影响。

## 数据

正文保存在节点的 `data.noteText`；尺寸与配色保存在节点的 `style`（`width`/`height` 与 `--note-bg`/`--note-color` 变量）。
