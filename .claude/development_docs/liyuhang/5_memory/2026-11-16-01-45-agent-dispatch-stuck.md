## STAR

**Situation**：派活回执「已入队」，目标节点却始终不运行，再发也没反应。
**Task**：找出队列卡死与「静默丢弃」的原因，保证任何路径都能释放节点。
**Action**：`runTask` 全流程 try/finally 并加超时；`pump` 兜底释放；去重键在任务结束时删除。
**Result**：dispatcher 7 例测试通过，web 已同步。

## 关键经验
1. 先登记「运行中」再执行，必须用 finally 保证释放；吞异常的 catch 会把节点永久锁死。
2. 去重是「防风暴」不是「防重试」，键必须随任务结束释放。
3. 本地 HTTP 调用也要加超时，否则最后一步清理也会被拖住。
