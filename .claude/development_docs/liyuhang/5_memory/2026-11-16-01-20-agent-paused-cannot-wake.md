# 记忆：停止后无法被唤醒

- 时间：2026-11-16 01:20
- 类型：bug 修复

## STAR

**Situation**：用户手动停止某个 Agent 后，其他 Agent 再派活给它会被静默丢弃。
**Task**：让「停止」只作用于停止这一刻的任务，不拒绝后续派活。
**Action**：删除 dispatcher 的 `pausedNodes` 状态及其入队/结果投递/canStart 门槛；保留 stop 清排队与 abort。
**Result**：dispatcher 5 例测试通过，web 已同步，待重启验收。

## 关键经验
1. 「停止」的语义边界要窄：停当前任务 ≠ 停这个节点。
2. 用「粘住节点」解决「停了又被拉起」，代价是把合法的新派活一起挡掉；应先清排队与回传，而不是封节点。
