# 记忆：Agent 建节点时可指定角色

- 时间：2026-11-16 00:50
- 类型：能力补充

## STAR

**Situation**：Agent 用 addNode 建出来的节点永远是通用角色，用户要手动补选。
**Task**：让模型能查到全局角色并在建节点时直接指定。
**Action**：新增画布工具 `getAgentRoles`（只给 id/名称/描述）；`addNode` 加可选 `roleId`，仅 Agent 节点生效，角色无效时按通用创建并回执说明；工具提示写清调用顺序。
**Result**：3 例 schema 测试通过；canvas.tool.js 与 web 资产已同步，待重启验收。

## 关键经验
1. 工具参数要让模型「查得到」：给 id 之前必须先有一个只读工具，否则模型只能猜。
2. 失效角色不该阻断建节点，回执说明比报错更符合「继续完成任务」的预期。
