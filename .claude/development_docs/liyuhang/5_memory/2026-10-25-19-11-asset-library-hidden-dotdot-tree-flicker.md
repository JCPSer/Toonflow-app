# 隐藏文件过滤、上级目录卡片、切库不再重建树（STAR）

## Situation

用户提三件事：素材库里还能看到 `.` 开头的文件；子目录没有"返回上一级"的入口（想按达芬奇那种双击回去）；每次切换全局/项目素材库，左侧目录树都会闪一下。

## Task

1. 隐藏文件不显示。
2. 子目录网格里固定一个 `..`，双击返回上一级。
3. 切库不重建树、不跳变。

## Action

- **隐藏文件**（`utils/assets/library.ts`）：`readChildren` 与 `reconcileRestoredPath` 跳过 `.` 开头的名字；旧接口 `listDeprecatedRoot` 同步处理。
- **上级目录**（`AssetGridView.vue`）：网格条件从 `entries.length` 改为 `entries.length || currentPath`，第一位渲染 `..` 卡片（`upCard`，双击 `emit("navigate", parentPath)`）；空态条件改为独立 `v-if="!loading && !entries.length"`，空目录仍能看到 `..` 与空态提示。
- **切库闪烁**（`useAssetLibrary.ts`）：`setLibrary()` 不再调用 `refreshTree()`。两个库的树根是同一套（项目分组 + 全局 / 本项目 + 全局），树实例原地复用即可，高亮与可交互状态由 `library` prop 驱动；顺带让 `AssetTreeView` 分组模式恢复 `expandedKeys`，并把外部变更的树重建改为 2s 节流。

## Result

- 库根放 `.隐藏.txt`、`.git/`，接口与界面都不显示。
- 进入子目录出现「.. / 上一级」，双击回根；空目录同样有 `..`。
- 切库逐帧测行数：首页 `10 → 10 → 10`（修复前 `6 → 10 → 9`），工作区 `5` 恒定；切库后高亮正确（项目库高亮项目名、全局高亮「全局」）。
- 两端类型检查与构建通过。

## 经验

- 闪烁往往不是"样式问题"，而是"重建了本该复用的组件"：先逐帧量一下 DOM，再决定改视觉还是改数据流。
- `:key` 触发的重建会把懒加载的子树全部作废；只要两棵树的根集合相同，就不该重建。
- "返回上一级"做成网格里的一个特殊卡片（而不是额外按钮），既符合文件管理器的直觉，也不占额外空间；空目录也要有，否则用户会被困住。
