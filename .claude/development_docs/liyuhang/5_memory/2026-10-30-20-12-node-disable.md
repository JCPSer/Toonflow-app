# 记忆：画布节点「禁用」

- 时间：2026-10-30 20:12
- 改动范围：42 个文件（nodeScaffold / nodeShared / 10 个节点包 / 画布前端 / 文档面板 / 服务端 mention），约 +935 / −119 行

## Situation

画布上的初级素材节点越积越多，既让画布变乱，也会被 Agent 的工具和 @ 引用误用。需要类似 ComfyUI mute 的实例级禁用：节点保留在画布、灰化，不参与执行、不可进入交互式操作、对 Agent 不可见，可随时解除。

仓库现状：`node.data` 无字段 schema（运行时）但 TS 侧 `NodeData` 是封闭类型；无全局执行器，执行由各节点按钮发起；撤销快照只记录 `data.label`；Agent 访问节点有 9 条路径（前端查询、@ 实时源、mention 直读、离线 JSON、自动上游注入、节点函数、结构回执、MCP 文档、文件直读）。

## Task

实现禁用/解除：持久化到 `node.data.disabled`；右键菜单、选区右键、浮动工具栏、快捷键四入口；灰化外观；执行链整条跳过；Agent 不可见；可撤销；运行中禁止禁用；文档/Agent 面板自动关闭。

## Action

- **状态**：`NodeData.disabled?: boolean`；`nodeSkeleton` 用局部 `computed(() => node.data?.disabled === true)`（不能读 `props.disabled`，Boolean prop 缺省会被 cast 成 false）。
- **执行**：`nodeInputs.readSourceValue` 对禁用节点返回 `undefined`；`getTargetValues` **保留** `{value: undefined, disabled: true}` 占位（禁止在 `getTargetSources` 过滤）；`NodeInputValue.disabled`；`useNodeReferences` 暴露 `disabledUpstreams`；6 个节点按钮置灰 + 首检文案。
- **Agent 过滤**：两个本地 `findNode` 加断言（按 ID 抛「节点已禁用」）；扫描类过滤并保留计数口径；`deleteEdges` 删前用非断言查找剔除端点；`disabledSignature` 纳入分页 revision；离线 mention 的 `byId` 保留完整、扫描过滤；`canvasHost` 的 outputs/select 守卫。
- **写入通道**：画布 `provide("toonflow:setNodeDisabled")`，顺序 flush 文档 → 失败不写 → 二次运行态检查 → `batch()` 写 → 关闭文档/Agent 面板；撤销/重做由「禁用集合」watcher 走 force 关闭。
- **撤销**：快照只存 `disabled === true`，恢复时缺失即 `delete`；删除后重建用快照值覆盖 `nodeReferences`；运行中节点跳过写回。
- **外观**：灰化 + 「已禁用」角标；top slot 不渲染、bottom slot 保留 + `inert` + 兄弟覆盖层（不盖 handle）；连线 `edgeDisabled`；小地图函数着色；搜索保留并标注；文件树/快速打开展示层过滤。
- **运行态**：`nodeBusy` 新增 `isNodeBusy` / `markNodeRunning` 与 `toonflow:node-busy-changed` 事件（跨 UMD 的响应式桥）。

## 经验

- 「禁用上游」绝不能从输入列表里过滤：过滤后下游的 `value === undefined` 守卫不触发，会在缺参考图的情况下静默生成。正确做法是保留占位并加 `disabled` 标记。
- `NodeData` 是封闭类型，加字段后它会变成 Vue 的 Boolean prop；节点骨架必须用 `node.data` 的局部 computed，读 props 会拿到 `false`。
- 画布与文档面板是兄弟组件，只能靠 `workspace` 页 provide；「先 flush 再写」必须做成唯一的 async 写入通道，否则各入口直写 data 会绕过原子性。
- 撤销/重做也会写 `disabled`，面板关闭必须挂在「禁用集合」watcher 上，不能只挂在主动禁用动作里。
- 跨 UMD 的全局 Map 不响应式：用 `window` 事件 + 宿主计数 ref 打通。
- 节点骨架的 top slot 承载悬浮条、bottom slot 承载参数区，禁用时只能隐藏 top、保留 bottom 并加 inert。
