# 变更记录：运行中复制 Agent 节点会永久丢失会话关联

时间：2026-10-29 19:19
类型：极小缺陷修复（单函数改动，未走完整 bug 流程，按规则记录）

## Situation

复制一个正在运行的 Agent 节点后，点开副本，会提示「分支会话创建失败，已按空会话开始」，副本从此变成空对话，再也接不回源会话。

## Task

让"源会话正在运行"这种**暂时性**失败可以重试，不再一次性丢弃待克隆指针。

## Action

`agentNodePanel.vue` 的 `loadSession`：

- 原来先 `updateNodeData({ agentSessionCloneFrom: undefined })` 再发请求，等于把唯一的重试凭据提前扔了；
- 改为请求成功后才清指针；
- 失败时按 `statusOf(error)` 分流：`409`（源会话运行中）保留指针、提示「等这一轮结束后再打开这个副本」并关闭面板，避免用户顺手在副本里建出新会话把指针顶掉；其它错误（源工程已删、文件不存在）仍然清指针，防止每次打开都重试坏指针。

## Result

- 运行中复制：副本保持"待克隆"，等源节点这一轮结束后再打开即可得到完整历史副本。
- 源工程删除等永久失败：行为与之前一致（提示后按空会话开始）。
- web 构建与部署通过（纯前端，刷新生效）。

## 附带确认（本次未改）

- 复制本身不拷贝文件、不碰会话锁，原节点继续运行不受影响。
- 副本未打开前，删源节点不会连带删除会话文件（`isAgentSessionReferenced` 认 `agentSessionCloneFrom`）。
- 副本不显示原节点的 `agentLastPrompt`。
