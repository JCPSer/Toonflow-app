## Situation

工程需要能分享出去：对方拿到一个文件就能导入并继续编辑。原始工程体积主要来自节点历史素材（每次生成落一份完整媒体），且图片视频未压缩。

## Task

导出自定义格式（压缩 + 可选口令加密）的可编辑工程副本：裁掉历史、只留展示所需媒体、媒体重新编码压缩；导入总是新建独立工程，永不覆盖。

## Action

1. **容器**：`TFPROJ\0\0` 魔数 + 64 字节头（version/flags/chunkSize/payloadSize/salt/nonce）+ `[manifest][entries]` 布局；媒体 `store`、文本 `deflate`、每条显式 `storedSize`；可选 scrypt(2^15, maxmem 128MiB) + 分块 AES-256-GCM（STREAM 构造 + 终止块防截断）。
2. **裁剪**：字段三级分类——展示必需（收集，缺了中止）/ 历史可回退（整块删除，`inpaint` 整个对象删）/ 可重建（不收）；文本节点正文里的 markdown 插图单独解析 `content.md`。
3. **压缩**：视频 → H.264 CRF24 ≤1080p 保留帧率与音轨；图片 → ≤2048 JPEG q3，含 alpha 保留 PNG/WebP；奇数宽用 `trunc(min(1920,iw)/2)*2`；换格式必须改名并改写画布 `mimeType`；并发 2。
4. **导入**：先写 `.partial` 再 `rename` 发布；缺 `.toonflow/ui.json` 与 `library/.library/index.json` 时补最小版本（否则缩略图破图、素材库降级为空）。
5. **ffmpeg 探测**：GUI 启动的进程 PATH 只有 `/usr/bin:/bin:/usr/sbin:/sbin`，补候选目录（`/opt/homebrew/bin` 等），不改全局 `process.env.PATH`。

## 经验

- **「按引用收集」是错的**：历史指针（`crop.previous`）本身就是引用，照收等于历史没删。必须先按字段语义分类再收集。
- **换容器格式却不改扩展名/mimeType 一定会坏**：前端按画布里的 `mimeType` 包装 Blob，字节与声明不符时 WKWebView 直接不播。
- **`decompressSync(data, {out})` 不报错只静默截断**，不能当解压炸弹防线，必须显式比对长度与 sha256。
- **scrypt 的 maxmem 是硬性要求**：默认 32 MiB 恰好卡在 N=2^15 的边界，不传直接抛。
- **WKWebView 拖入文件拿不到绝对路径**，只能上传字节；也因此「口令错误后删临时文件」会让加密包的重试彻底失效。
- 桌面应用的 PATH 与终端不同，任何依赖 `which` 的能力都要自己补候选目录。
