# 记忆：Agent 节点（画布内嵌 agent 会话）

## Situation

画布只有素材/生成类节点，多步流程必须回右侧主对话操作。用户要把 agent 本身变成节点：接上游素材、给它任务、它自己改画布，产物留在画布上。需求经 10 轮追问定下 14 条决策（输入只当上下文、每节点独立会话、与主对话同权、技能每轮临时选、面板跟随节点且唯一、上游自动注入、跟随全局模型、复制分叉、删除等撤销窗口、四态状态、关闭不取消、分支出新节点）。

## Task

新增 `Agent` 节点类型（仅输入端口），每个节点绑定自己的 agent 会话，用一块跟随节点、同一时刻唯一的对话面板承载交互，并把会话的生命周期（创建/复制/删除/历史可见性）与画布撤销、复制、清理链路对齐。

## Action

- **契约先冻结**（`nodeScaffold/src/agentNode.ts`）：`AGENT_NODE_STATUS_KEY = Symbol.for("toonflow.agentNodeStatus")` 让宿主 provide 与 UMD 节点包 inject 跨 Bundle 对上；`useAgentNodeStatus()` 只读。状态表放画布层、不写 `node.data`（data 有 500ms 防抖保存）。
- **节点包** `packages/nodes/agentNode`：只有 target `in`（`dataType:"*"`），`outputs: {}`；状态行四态、最近提问摘要、上游端口摘要；`nodeEvent.on("copy")` 返回 `{ agentSessionFile: undefined, agentSessionCloneFrom: <源> }`，把「分叉」推迟到首次打开。
- **对话面板** `canvas/components/agentNodePanel.vue`：挂在 `<vue-flow>` 内（继承该画布实例的 `provide("canvas")`，`useVueFlow(runtimeKey)` 拿同一 store）；固定像素尺寸 + `viewport/computedPosition` 计算位置，右缘越界翻左并夹在画布内；`v-show` 保活，运行中关闭只隐藏（卸载会 abort 请求）。
- **conversation.vue** 扩展：`extraMentions/acceptPending/showModelPicker/nodeBinding` 四个入参、`promptStart/status/sessionLost` 三个出参；`phase` 状态机（thinking → running → waiting，rewind/删光回 idle）；上游引用注入同时补 `{{mention:id}}` 令牌（服务端校验成对出现），空输入不因补引用变成可发送。
- **服务端**：`nodeBinding` 落 `toonflowAgentNode` 自定义条目（幂等、失败只记日志），`listAgentSessions` 按 `"customType":"toonflowAgentNode"` 前 8KB 过滤；新增 `POST /api/agent/clone`（运行中 409、逐字节拷贝 + 追加 session_info）与 `DELETE /api/agent/session`（409 守卫、缺失幂等、递归清理子会话）。
- **画布链路**：删除时先记账，等 `onNodesDropped`（撤销栈淘汰）再删会话，删除前检查是否仍被其它节点的 `agentSessionCloneFrom` 引用；`canvasFiles.ts` 的另存/导入把 `agentSessionFile` 改写成 `agentSessionCloneFrom`，覆盖所有复制路径。

## Result

四个包 typecheck 0 新增错误；`deploy-local.sh --build` 全量重建并安装（节点包 10 个）。

评审（2 blocker + 9 should-fix）全部落实：新节点模型兜底、加载完成前不挂载对话、唯一面板、`getNodes` 原地增删监听失效（改监听 id 串）、克隆失败不污染指针、空输入不被引用放大、上游引用实时刷新、清理前查引用、子会话递归删除 + 409 重试、克隆运行中源 409、首轮未落盘的 404 自愈、Delete 快捷键不再误删节点。

未验证：面板跟随在 50%/200% 缩放下的实际像素误差、真实 WKWebView 下的拖动跟手性，需要重启后手测。
