# 记忆：Agent 派发关系可视化

- 时间：2026-11-16 00:20
- 类型：新能力

## STAR

**Situation（背景）**
Agent 之间已能派活，但谁派给谁、排队还是运行，只能打开面板看会话。

**Task（任务）**
在画布上用临时有向箭头显示 A→B 派发与 B→A 回传，带状态色和悬停摘要，不污染画布数据。

**Action（行动）**
- dispatcher 维护内存 `AgentLink[]`：入队灰、运行蓝、结束按结果着色；结束时派发线退场、换成 1.6 秒回传脉冲；stop/丢弃任务/dispose 都清理。
- 新增 SVG 叠加层，按节点坐标 × zoom + viewport 画贝塞尔箭头；marker id 按实例隔离，层放在 vue-flow 插槽内且低于对话面板。
- 命中区 `pointer-events:none`，用 `isPointInStroke` 做悬停命中，避免拦截画布拖拽与滚轮。
- 几何抽成纯函数并补 4 例单测；dispatcher 补 2 例链接生命周期测试。

**Result（结果）**
9 例前端测试通过；web 资产已同步到应用，待重启验收。

## 关键经验

1. Vue Flow 的默认插槽在 `.vue-flow` 内、pane 之外：放这里才是屏幕坐标又能被面板盖住。
2. 叠加层不能靠 pointer-events 做命中，否则会吞掉画布拖拽/滚轮；用几何命中测试把事件留给画布。
3. 多画布宿主会保留隐藏实例，SVG marker id 必须按实例唯一，否则箭头会解析到隐藏 defs 而不显示。
4. 关系线是内存态：所有丢弃任务的路径都要配套清理，否则会留下永久灰线。
