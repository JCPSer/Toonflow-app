# Bug 分析：开启网格吸附后仍有节点轻微错位

- 时间：2026-10-29 19:40
- 现象：画布已开启「网格吸附」（`snapToGrid` + `snapGrid = [16,16]`），但总有部分节点看起来比其它节点偏一点点，刷新/重启后依旧。
- 优先级：P1（不阻断功能，但持续影响布局观感，用户明确表示难以忍受）
- 难度：中（多点位的小改动 + 一个加载期归一化）

## 一、现象取证

直接读现有画布文件的节点坐标（`toonflowCanvas` JSON），按 16 取模统计：

| 画布 | 节点数 | 不在 16 网格 | 特征 |
| --- | --- | --- | --- |
| 蕾姆Rem/1-早上起床-特殊唤醒服务 | 28 | 7 | 全部是分组与组内节点，偏移量恒为 8 |
| 蕾姆Rem/4-教学楼天台的大胆行为 | 28 | 11 | 同上，另有 1 个小数坐标 `968.5499…` |
| 黒木/女人物换头 | 3 | 3 | 三个根节点全是小数坐标 |

两种形态：
1. **整数偏移 8px**：分组 `(952,920)`（952/16=59.5），组内相对坐标 `24/40/296/536/584`。`24 mod 16 = 8`、`40 mod 16 = 8`。
2. **小数坐标**：`1474.792116359792`、`781.6969722839785`、`1108.8604270695755`、`968.5499504661576`。

同文件里也有对齐完好的分组：组内最小相对坐标为 `32/48`（是 16 的倍数），说明分辨率存在两条不同的建组路径。

## 二、根因

只吸附"拖拽"这一步是不够的：Vue Flow 的 `snapToGrid` 只作用在 `useDrag` 与 `project()` 上（`vue-flow-core.mjs:4929`、`3687`），凡是项目自己写 `position` 的地方都不经过它。具体点：

| 编号 | 位置 | 问题 | 产物 |
| --- | --- | --- | --- |
| R1 | `selectionNodes.ts:44-47` `fitGroupBounds` | 建组内边距用 `-24 / -40`，右侧与底部 `+24`；24、40 不是 16 的倍数 | 组位置偏 8，子节点相对坐标 24/40 → 绝对坐标永久偏 8 |
| R2 | `selectionToolbar.vue:131` `groupNodes` | 同上（`bounds.x - 24`、`bounds.y - 40`、宽高 `+48/+64`） | 同上 |
| R3 | `selectionToolbar.vue:106` `duplicateNodes` | 副本偏移 `bounds.width + 64`，`bounds.width` 是 DOM 量出的节点宽度（图片节点常带小数） | 副本坐标带小数 |
| R4 | `arrangeSelection.ts:53-59` | 间距 80 没问题，但垂直/水平居中有 `(rowHeight - nodeHeight)/2` | 高度差为奇数时出现 .5，与已有小数叠加 |
| R5 | `groupNode.vue:160-178` 分组缩放 | `screenToFlowCoordinate` 除以 zoom，宽高、`position`、子节点 `dx/dy` 全部直接写回 | 组与全部子节点变成小数 |
| R6 | `agentNodePanel.vue:396` 复制 Agent 节点 | 偏移 `width + 80`，`width` 非网格倍数 | 副本偏 8 或非整数 |
| R7 | 历史数据 | 上述路径产生的坐标已落盘，修复代码不会自动纠正存量 | 旧画布继续错位 |

推论：**新建的东西就可能已经不在网格上**，拖拽只能把它拖到网格上（拖拽是吸附的），但分组内的子节点拖不动（拖的是组），所以组内 8px 偏移是"永久"的。

## 三、修复目标

1. 所有由我们代码写入的位置，一律先吸附到当前网格，再写回（R1-R6）。
2. 分组内边距改为网格倍数（32 / 48），保证"组在网格上 → 子节点也在网格上"。
3. 打开画布时，对已有数据做一次归一化（R7）：`snapEnabled` 为真才做，组内间距保持不变（整组平移），一次批量可撤销。

## 四、风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 归一化改动了用户既有布局 | 节点相对位置微调 ≤8px | 组内统一平移，间距不变；只在真的越界时触发；整体一次 `canvasHistory.batch`，可一键撤销 |
| 加载期写入触发保存 | 打开画布就产生一次写盘 | 无变化时完全跳过，不写文件 |
| 分组内边距变大 | 组比原来宽/高 16px | 只在新建/重排时生效，旧的保持原样直到归一化 |
| 缩放吸附 | 拖手柄变成 16px 一档，手感变粗 | 只吸附最终写回值，不做逐帧吸附 |
