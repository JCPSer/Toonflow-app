# Bug 分析：Agent 对话面板向上滚动时内容跳动

- 时间：2026-11-02 10:30
- 提出人：用户
- 现象：在 Agent 对话面板里**往上翻历史**时，滚动过程中内容不断错位跳动（几行幅度）；向下翻与停在原地正常
- 状态：根因已定位，方案见 `bug_solution-2026-11-02-10-30-agent-message-up-scroll-jump.md`

## 1. 背景

对话消息列表是虚拟列表（`@tanstack/vue-virtual@3.13.39`，实际运行 `@tanstack/virtual-core@3.17.11`）：

- 行高动态（markdown、图片、工具卡片差异大），`estimateSize` 固定 240px；
- 行绝对定位 + `translateY(start)`，`measureElement` 回写实测高度；
- 开启 `anchorTo: "end"`、`followOnAppend`、`scrollEndThreshold: 48`，贴底时随新消息跟随。

## 2. 复现与定位

| 步骤 | 结果 |
| --- | --- |
| 用户操作：对话面板内向上翻历史 | 滚动过程中一段一段跳；向下翻不跳；停下后位置正确 |
| 代码核对 | 初次测量（估算 240 → 实测）会被补偿；但「重复测量」在 `scrollDirection === "backward"` 时被库显式跳过补偿 |
| 上游核对 | TanStack/virtual #1227：3.14 起 `resizeItem` 在向上滚动时跳过视口上方行高补偿，动态测量列表因此抖动；3.17.x 的回调开关未从 options 读取，需按实例属性赋值 |

结论：向上滚动时，视口上方（已测量过或正在加载图片/字体而变高的）行每变化一次，下方内容整体位移一次，而库不再补偿 `scrollTop`，于是表现为「一路跳」。

## 3. Bug 矩阵

| 编号 | Bug | 优先级 | 复杂度 | 风险 |
| --- | --- | --- | --- | --- |
| B1 | 向上滚动时，视口上方行高变化不补偿 scrollTop，内容错位跳动 | P1（影响阅读） | 低（实例回调一行） | 中：库作者当年因「连锁补偿」移除该默认行为，需要实测 |
| B2 | 直接升级 TanStack Virtual 也能修，但会动锁文件并牵动其它虚拟列表（提及菜单） | — | 中 | 中：回归面大于本次问题 |

## 4. 不在本次范围

- 不改 `estimateSize`、`overscan`、`anchorTo` 等布局参数。
- 不升级依赖版本。
- 不改工具卡片折叠、轮次目录跳转等既有逻辑。

## 5. 验收标准

1. 向上翻历史：滚动过程中内容不再一段一段错位；滚动条位置自然。
2. 向下翻、贴底跟随新消息：与现在一致。
3. 展开/收起工具卡片、轮次目录跳转：位置行为不变。
4. 实时回复流式增长时：视口不被拽动。
