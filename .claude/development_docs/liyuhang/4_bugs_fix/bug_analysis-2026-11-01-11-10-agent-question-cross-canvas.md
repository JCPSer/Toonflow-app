# Bug 分析：Agent 提问横幅只在提问节点所在画布显示

- 时间：2026-11-01 11:10
- 分支：`feat/exec-node`
- 提出人：用户

## 1. Bug 背景

画布 Agent 节点在等待回答时，顶部会出现「N 个 Agent 正在等你回答」横幅。用户同时打开多块画布，Agent 在画布 A 提问时，画布 B 看不到任何提醒，只有切回画布 A 才显示。

## 2. 现象

1. 在画布 A 的 Agent 节点发起提问；
2. 切换到画布 B，顶部没有提问横幅；
3. 切回画布 A，横幅出现。

## 3. 根因

- 画布实例由 `canvasHost.vue` 同时挂载，后台画布只是 `hidden + inert`，不卸载；
- 提问列表 `agentQuestions` 是 `canvas/index.vue` 的组件内 `ref`，只由本画布的 `agentNodePanel` 写入；
- 横幅模板也只在各自画布实例里渲染，所以后台画布的横幅跟着隐藏 DOM 一起不可见；
- 任务完成提醒已经用全局 store（`stores/taskAlerts.ts`）解决同类问题，提问提醒没有做。

## 4. Bug 矩阵

| 编号 | 描述 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| B1 | 提问提醒在非来源画布不可见 | P1 | 低 | 需要把组件内状态提升为全局 store |
| B2 | 跨画布点击要能跳到来源画布并打开对应 Agent 面板 | P1 | 中 | 实例之间拿不到对方的 Vue Flow，需沿用 activateCanvas + pendingFocus |
| B3 | 回答/关面板/删节点/卸载画布后不能留下点不开的幽灵条目 | P1 | 低 | 按 canvasKey 整组同步 |
| B4 | 画布改名/另存后 canvasId 变化，旧条目不能指错文件 | P2 | 低 | 监听 canvasId 同步 store |

## 5. 不在本次范围

- 跨项目提醒：离开项目会销毁工作区并中断 Agent 请求，不存在其他项目的提问。
- 修改 Agent 面板内部未读判定或音效。

## 6. 验收口径

1. 画布 A 提问后切到画布 B，B 顶部立即出现横幅，条目带画布名与节点名。
2. 在 B 点条目：自动切到 A、定位节点并打开 Agent 面板，横幅条目消失。
3. 在 A 回答后，B 的横幅同步消失。
4. 关闭画布 A 后，B 上属于 A 的条目消失。
5. 画布 A 改名后，从 B 点击仍能切到 A。
6. 单画布场景行为与改动前一致。

## 7. 评审意见

| 评审人 | 结论 | 意见 |
| --- | --- | --- |
| 用户（选择题确认） | 通过 | 所有画布顶部横幅显示；点击切过去并打开 Agent 面板。 |
| 子 Agent 审查 | 通过 | 无 P1；4 条 P2 已整改 3 条，跨画布跳转与任务提醒重复暂不抽象。详见 `3_test_results/2026-11-01-11-10-agent-question-cross-canvas.md`。 |
