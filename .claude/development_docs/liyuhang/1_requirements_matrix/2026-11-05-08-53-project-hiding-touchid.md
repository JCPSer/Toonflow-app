# 需求矩阵：项目隐藏（Touch ID 验证）

- 时间：2026-11-05 08:53
- 提出人：liyuhang
- 状态：已与用户逐项确认（grill-me），待评审

## 1. 需求矩阵

| 项目 | 内容 |
| --- | --- |
| 背景 | 用户有隐私项目，需要把软件给别人演示时不显示这些项目；首页左侧/中部项目区目前只有一个列表，没有隐藏能力 |
| 目标 | 桌面端应用内所有入口都能隐藏指定项目；解锁需 macOS Touch ID（可回落系统登录密码）；重启后自动重新锁定 |
| 优先级 | P1（隐私相关，演示刚需） |
| 难度 | 中（涉及原生 LocalAuthentication、主进程 RPC、服务端路由、首页/画布/素材库多处过滤） |
| 风险 | 中：①「隐藏」只是 UI 层，磁盘上的项目文件仍是明文，Finder 可直接看到；②需要更新已安装应用的主进程包与原生库，必须重启应用；③原生验证若不可用（非 Mac、远程/浏览器）需要明确降级 |

### R1 标记隐藏 / 取消隐藏

- 普通项目卡片悬停时在「重命名 / 删除」旁新增一个「隐藏」按钮（眼睛带斜杠图标），点击立即隐藏，无二次确认。
- 隐藏项目 tab 内同一位置变为「取消隐藏」（眼睛图标），点击立即恢复。
- 隐藏标记保存在项目列表项上（`Project.hidden`），与 name/lastOpenedAt 一起持久化到 `data/settings.json` 的 `settings.stores["toonflow.projectList"]`。

### R2 首页「项目 / 隐藏项目」切换

- 未解锁时：项目区标题右侧只显示一个锁图标按钮（悬停提示只写「解锁」），不出现「隐藏项目」字样；点击后才弹系统验证。
- 解锁后：显示「项目 / 隐藏项目」分段控件，可来回切换；旁边保留锁图标用于立即锁定。
- 解锁成功后停留在「项目」页，由用户自行切到「隐藏项目」。
- 默认停在「项目」页；解锁状态与 tab 选择都不持久化，重启回到「项目」锁定态。
- 隐藏项目 tab 复用现有网格与卡片，支持打开、重命名、取消隐藏、从列表移除。

### R3 设置开关

- 设置 → 隐私 面板新增「显示隐藏项目」开关。
- 打开：调用系统验证，通过后解锁（等价于首页锁图标解锁）；取消/失败则保持关闭。
- 关闭：立即锁定，首页若停在隐藏项目 tab 则跳回「项目」。
- 非桌面环境（浏览器/手机远程）不显示该开关。

### R4 解锁与验证

- 验证方式：macOS LocalAuthentication，`LAPolicyDeviceOwnerAuthentication`——优先 Touch ID，识别失败或设备无生物识别时由系统提供「输入密码」回落。
- 解锁状态只在本次进程内存中有效：应用重启/完全退出后自动锁定；提供手动「立即锁定」。
- 验证失败、取消、系统不弹窗时：保持锁定并提示，不提供绕过。
- 已验证本机 macOS 15.7 上非签名的独立 Mach-O 进程可以直接调用 LAContext 并成功弹出验证（见测试文档）。

### R5 全应用入口一致（桌面端）

锁定状态下，以下入口一律不显示隐藏项目：
- 首页项目网格（R2 已覆盖）；
- 画布顶部项目下拉（`canvasMenu` 的项目列表与搜索）；
- 首页素材库的「项目」分组；
- MCP/外部控制返回的项目列表与 settings 快照。
- 例外：设置 → 设备连接 的默认允许目录保持完整——远程设备本身就是按 R7 照常访问隐藏项目，过滤会把远程功能弄坏。

### R6 恢复上次项目时拦截

锁定状态下进入 `/workspace`（应用重启后直接访问或浏览器历史恢复），若当前项目是隐藏项目：不进入工作区，跳回首页并提示「该项目的隐藏状态已锁定，请先验证」。验证通过后可正常进入。

### R7 非桌面环境

浏览器直连、手机远程/设备连接、MCP 这类没有 Touch ID 的环境：隐藏项目照常显示（用户确认），不提供解锁入口；桌面端 WKWebView 仍是锁定态。

### R8 判定与兜底

- 原生验证不可用（非 macOS、dylib 缺失/加载失败、系统无可用认证、远端桌面连接）：首页锁图标点击提示「当前环境不支持系统验证」，保持锁定。
- 安装包不具备验证能力时（Windows 构建、旧安装包、验证库缺失）**禁止隐藏项目**，避免「藏进去再也解不开」。
- 隐藏项目在磁盘上仍可被 Finder/命令行看到，应用不承诺加密（已知边界，需在设置项描述中说明）。

## 2. 验收标准

1. 桌面端首页项目区锁定态只有锁图标；点击后弹 Touch ID，验证通过出现「项目 / 隐藏项目」分段。
2. 普通项目悬停可点「隐藏」，项目立刻从「项目」页消失；切到「隐藏项目」页能看到。
3. 隐藏项目页点「取消隐藏」，项目回到「项目」页。
4. 设置 → 隐私 →「显示隐藏项目」：打开需验证，关闭立即锁定；关闭时首页跳回「项目」页。
5. 重启应用后处于锁定态：首页看不到隐藏项目，画布项目下拉、素材库项目分组、设备连接默认目录里也看不到。
6. 上次打开的是隐藏项目时重启并进入工作区：被拦回首页并提示验证；验证后在「隐藏项目」页手动打开即可进入。
7. 取消验证 / 验证失败：保持锁定，不出现隐藏项目。
8. 手机远程/浏览器访问：隐藏项目照常显示。
9. 隐藏状态在重启后保持（settings.json 中 `hidden: true`），且打开项目不会把 hidden 标记冲掉。
