# 需求矩阵：Agent 交互区易用性 + 素材库两项改进

- 记录时间：2026-10-27 17:04
- 需求来源：用户 2026-10-27 提出的四条 agent 交互区需求，追加两条素材库问题/需求
- 代码基线：`16f7fb2`（工作树干净）

## 一、背景

Agent 交互区（右侧对话面板 / 全屏对话）落成后，日常高频操作还有明显摩擦：

1. 输入框不能像终端一样用 ↑/↓ 找回刚发过的内容，误删/改字只能重打。
2. 富文本编辑器（x-sender 1.4.6）自行接管了左右方向键（`preventDefault + cursorMove(±1)`），导致 macOS 的 ⌘←/→（行首行尾）、⌘↑/↓（文首文末）失效。
3. 新建项目走 `Utils.openFileDialog`（electrobun 预编译原生层），macOS NSOpenPanel 的 `canCreateDirectories` 未开启，面板里没有"新建文件夹"，只能去 Finder 先建好再回来选。
4. 文本节点内部用 `runAgentLoop` 跑生成，思考/生成期间节点外观毫无变化，看不出是否在跑。
5. 素材库把 174 MB 视频拖到画布时，前端先 `GET /api/assets/read` 取整块 Blob，再 `uploadNodeFile` 回传，触发 Express 100 MB 请求体上限，报 `entity too large`。
6. 素材库右键菜单没有"在访达中显示"，管理素材必须自己去找目录。

## 三、非目标

- 不提高 Express 全局 100 MB 请求体上限，不改造为流式/分片上传。
- 不改 Windows 原生对话框（IFileOpenDialog 自带新建文件夹），不魔改 electrobun。
- 不做跨会话、跨项目的全局历史（R1 仅当前会话）。
- 不把原生目录选择整体替换为应用内自绘浏览器。
- 不改造其他节点（图片/视频/音频）的运行态展示，本轮只做文本节点。

## 四、验收标准

1. 空输入框连按 ↑：依次出现当前会话最近的用户消息；按 ↓ 逐条回到最新后变回空；发送后再次按 ↑ 能翻到刚发送的内容。
2. 输入框有文字时按 ↑/↓ 不翻历史，光标行为与现在一致。
3. 对话输入框与节点提示词输入框内：⌘←/→ 移到行首行尾，⌘↑/↓ 移到文首文末，⌘⇧ 组合可选中；@ 提及 / 斜杠菜单展开时方向键仍用于菜单导航。
4. 桌面端点"选择工作目录"弹出系统原生面板，面板内有"新建文件夹"，新建后可直接选中并创建项目。
5. 文本节点点击生成后出现边框动画，思考阶段与流式生成阶段都可见，结束/失败/停止后消失；系统开启"减少动态效果"时降级为静态描边。
6. 从素材库拖 174 MB 视频到画布：节点正常创建、视频可播放；浏览器网络面板不再出现整块素材上传请求；同盘时工作区文件与素材库文件 inode 相同（`ls -i` 校验），跨盘时回退为复制且仍可播放。
7. 素材库右键"在访达中显示"：打开 Finder 并选中对应文件/文件夹；远程连接、移动端与无桌面运行时的网页端不显示该菜单项。

## 五、评审意见

- 子 agent 初审（2026-10-27 17:10）：
  - R1 数据通道缺失：`messages` 只在 `conversation.vue:109` 的本地 ref，未传给 `messageInput`（`messageInput.vue:79`）；历史还原必须复用 `fillRewind`（`:268`）才能保留提及/附件；"草稿为空"需同时排除附件与提及。已采纳，写入 R1 与验收标准。
  - R2 x-sender 的 `text-move` 只看 `!shiftKey`，不判 meta/ctrl/alt（`XSender.mjs`），⌘←/→ 与 Windows Ctrl+←/→ 都被 `preventDefault+cursorMove` 劫持；`text-updown` 不判修饰键，⌘⇧ 组合要走单独路径；移动后需同步光标缓存。已采纳为方案要点。
  - R3 改造点唯一（`apps/desktop/src/index.ts:501-504`），但 `routes/workspaces/selectDirectory.ts` 的 osascript 仅 nativeDevelopment 生效，不能直接复用；需处理取消、realpath、窗口置前与 TCC 风险。已采纳。
  - R4 应把 `running` 做成 `nodeSkeleton` 显式 prop，class 落 `.contentCard`，用 outline/box-shadow 避免覆盖 selected 边框；已有 reduced-motion 先例。已采纳。
  - R5 413 来自 `/api/workspaces/files/write` 的 raw 100 MB（`app.ts:54`），不是 assets/read；现有 `/api/workspaces/files/copy` 被工作区校验拦住，不能跨库复用，需要新增 `/api/assets/copyToWorkspace`。已采纳；并按用户决定改为硬链接优先。
  - R6 reveal.ts 的整条路由依赖工作区授权，素材库不能直接复用，需要独立 `/api/assets/reveal`；前端还需处理"生产 Web 无桌面运行时"时的隐藏。已采纳。
