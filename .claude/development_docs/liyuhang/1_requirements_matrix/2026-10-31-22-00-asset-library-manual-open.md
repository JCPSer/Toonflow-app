# 需求矩阵：素材库面板改为纯手动开关（含滑入动画）

- 时间：2026-10-31 22:00
- 状态：已实现

## 一、需求背景

画布界面下的素材库面板会出现「没点它自己弹出来」的情况，用户希望面板只由手动开关控制，并且在点开时有从左向右的滑入动画。

## 二、需求矩阵

| 编号 | 需求 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | 取消「保存到素材库」时自动展开面板 | P0 | 低 | 低 |
| R2 | 保存弹窗仍然正常弹出（不依赖面板可见） | P0 | 低 | 低（弹窗 appends to body） |
| R3 | 保留「上次打开状态」的会话恢复（用户选择保留） | P1 | 无 | 低 |
| R4 | 手动打开素材库时从左向右滑入，关闭时反向滑出 | P0 | 低 | 低 |
| R5 | 动画只作用于素材库，不影响共用 `floatingPanel` 的 Agent 面板 | P0 | 低 | 低 |
| R6 | 尊重系统「减少动态效果」设置 | P1 | 低 | 低 |

## 三、非目标

- 不改变面板停靠/浮层布局、拖拽、尺寸记忆。
- 不改变保存到素材库的业务流程与目标库选择。

## 四、验收标准

1. 节点/选区执行「保存到素材库」时弹窗出现，素材库面板保持原状态（关着就还是关着）。
2. 只有点击画布工具条的素材库按钮才会打开面板。
3. 打开时面板自左向右滑入，关闭时反向滑出，约 0.24s。
4. Agent 面板显隐不受影响。
5. `bun run --cwd apps/web typecheck` 仅剩既有无关报错，构建通过。

| 评审人 | 结论 | 意见 |
| --- | --- | --- |
| 用户 | 通过 | 弹窗照常、保留状态恢复、左→右滑入+反向滑出 |
