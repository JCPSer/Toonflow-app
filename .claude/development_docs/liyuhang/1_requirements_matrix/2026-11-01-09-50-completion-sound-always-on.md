# 需求矩阵：节点提示音改为无条件播报

- 时间：2026-11-01 09:50
- 分支：`feat/exec-node`
- 提出人：用户

## 1. 需求背景

用户反馈提示音存在「有条件不播报」：窗口在前台时不响，怀疑看不到节点时也不响。希望改成「全都播报」——不管窗口是否在前台、Agent 面板或该节点是否在看，都出声。

## 2. 需求目标

- 节点完成/失败与画布 Agent 提问提示音，在开关开启时一律播放，不再判断窗口焦点。
- 移除与前后台绑定的「仅后台」档位，避免选项文字与实际行为不符。
- 保留防噪门槛：30 秒以内完成的任务、手动停止、1 秒内重复事件仍不重复播报。
- 系统通知不属于本次范围，仍只在窗口失焦时发送。

## 3. 需求描述

| 编号 | 需求 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | `shouldPlayChime` 只判断开关，不再读 `document.hasFocus()` | P0 | 低 | 前台工作会被提示音打断，需用户明确接受 |
| R2 | 设置页「节点提示音」改为「开启 / 关闭」两档，文案说明前台后台都会响 | P0 | 低 | 旧值 `background` 需要兼容迁移 |
| R3 | 画布工具条铃铛同步改为两档循环，tooltip 显示「提示音：开启/关闭」 | P0 | 低 | 旧配置读到时需归一化为开启 |
| R4 | 旧配置中的 `background` 视为开启，不静默变关 | P0 | 低 | 迁移只发生在前端读取层 |
| R5 | 保留 30 秒任务门槛、手动停止不响、1 秒合并窗口 | P1 | 低 | 不能把噪音一起放开 |
| R6 | 系统通知 `shouldNotify` 维持「仅后台」，本次不改 | P1 | 低 | 避免范围蔓延 |
| R7 | 不新增测试文件，遵守 AGENTS 测试边界 | P0 | 低 | — |

## 4. 不在本次范围

- 不改提示音音色、音量、音型（成功/失败/提问仍各自区分）。
- 不改系统通知的触发条件与内容。
- 不改节点运行、Agent 提问的产生与未读横幅逻辑。

## 5. 验收口径

1. 开关为「开启」时，窗口在前台：节点完成/失败提示音、Agent 提问提示音都会响。
2. 窗口在后台时同样会响，与改动前 `always` 档一致。
3. 开关为「关闭」时一律不响。
4. 旧配置 `completionSound: "background"` 升级后表现为「开启」，工具条与设置页都显示开启。
5. 运行不足 30 秒的节点、手动停止的节点仍不响；1 秒内的密集事件只响一次。
6. 系统通知仍只在窗口失焦时发送。
7. 设置页描述与实际行为一致，不再出现「仅后台」。
