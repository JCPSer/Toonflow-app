# 需求矩阵：图片节点颜色调整工具

- 时间：2026-11-13 18:26
- 模块：`packages/nodes/imageNode`（新组件，图片生成节点共用）
- 状态：已实施

## 1. 需求背景

图片节点有裁剪/缩放/打光/局部重绘等工具，但没有最基础的颜色校正。生成图偏色、偏暗、发灰时只能重新生成或去外部软件处理。

## 2. 需求描述

在画布节点工具栏加「调整」入口，弹窗里用五根滑杆调亮度、对比度、饱和度、色温、色调；弹窗内实时预览，应用后落盘新图并替换输出，支持「恢复调整前」。

## 3. 需求矩阵

| # | 描述 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | 五根滑杆：亮度 / 对比度 / 饱和度 / 色温（冷↔暖）/ 色调（绿↔品红），范围 -100..100 | P1 | 中 | 中（公式选得不好会调不动或一调就爆） |
| R2 | 预览实时反映参数，且与导出结果一致 | P0 | 中 | 高（预览与导出不一致等于骗人） |
| R3 | 应用后落盘新图、替换输出，可「恢复调整前」 | P1 | 中 | 中（与裁剪/缩放的状态机一致才不出脏状态） |
| R4 | 图片节点与图片生成节点共用同一组件 | P1 | 低 | 低 |
| R5 | 切图/禁用/切画布/拖动节点时自动关闭，避免残留预览 | P2 | 低 | 低 |
| R6 | 大图（>64MP）给出明确错误而不是卡死或产出空白 | P2 | 低 | 中 |

## 4. 非目标

- 不做曲线/色阶/HSL 分区调整，不做局部蒙版调整。
- 不做非破坏式参数保存（参数不落 data，导出即固化）。
- 不在节点卡片上直接显示调整后的滤镜预览。
