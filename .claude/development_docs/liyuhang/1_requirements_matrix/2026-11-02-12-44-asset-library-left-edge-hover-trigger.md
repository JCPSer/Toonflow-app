# 需求矩阵：素材库左边缘悬停入口

- 时间：2026-11-02 12:44
- 提出人：用户
- 状态：已与用户确认（grill-me 逐项确认）

## 1. 需求背景

素材库面板（`floatingAssetLibrary.vue`）是工作区级的左右浮动面板之一，默认停靠左侧宽 360px。目前唯一的入口是画布左下角工具条里的文件夹按钮（`canvasControls.vue`）：

- 入口藏在工具条中间，第一次使用的人不容易发现；
- 文档面板激活时工具条随画布一起隐藏，文档面板里没有任何入口；
- 面板关闭后，想再打开必须回到画布左下角找按钮。

用户希望在最容易到达的位置——窗口左边缘竖直居中——提供一个悬停即现的入口：鼠标贴到左边缘出现一个圆形按钮，点击打开素材库，鼠标移开按钮消失。

## 2. 需求目标

1. 窗口左边缘竖直居中提供悬停入口，鼠标移入触发区出现按钮，移出后消失。
2. 点击按钮打开现有素材库面板，沿用现有的停靠/浮层与宽高状态，不新增面板形态。
3. 不占用画布左边缘的常驻空间，不改变画布拖拽、框选、迷你地图、左下工具条的现有交互。
4. 入口只在素材库关闭时出现；打开后入口自动隐藏，关闭后重新可用。

## 3. 需求描述

### 3.1 功能需求

| 编号 | 需求 | 优先级 | 说明 |
| --- | --- | --- | --- |
| R1 | 悬停出现 | P0 | 指针进入「左侧 12px × 竖直居中 160px」的隐形热区时，圆形按钮从左侧滑入并淡入 |
| R2 | 移开消失 | P0 | 指针离开热区与按钮（含 160ms 缓冲）后按钮滑出淡出；鼠标离开窗口、窗口失焦同样立即收起 |
| R3 | 点击打开 | P0 | 点击按钮把 `assetLibraryStore.visible` 置为 true，面板按现有停靠/浮层设置与宽高打开 |
| R4 | 打开后隐藏入口 | P0 | 素材库可见时入口整体不渲染；关闭面板后回到悬停可用 |
| R5 | 面板与按钮形态 | P0 | 直径 36px 圆形按钮，文件夹图标，距左边缘 8px、竖直居中，与左下工具条圆形按钮同一视觉语言 |
| R6 | 两面板共用 | P0 | 画布面板与文档面板激活时都生效（工作区级组件，不挂在画布内部） |
| R7 | 无障碍 | P1 | 按钮有 `aria-label="打开素材库"` 与 title；键盘 Tab 聚焦时按钮显示，Enter/Space 打开 |
| R8 | 不遮挡 | P1 | 热区只在左边缘 12px 内，按钮显示后最多占 44px 宽；不覆盖左下迷你地图与工具条 |

### 3.2 非功能需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| N1 | 不引入常驻 DOM 阻塞 | 热区容器 `pointer-events: none`，只有热区条与按钮本身接收指针，画布在其余区域完全不受影响 |
| N2 | 不增加画布渲染负担 | 只用 CSS transform/opacity 过渡，不监听画布每帧事件，不读 Vue Flow 状态 |
| N3 | 可维护性 | 组件独立于画布与素材库面板，只依赖 `assetLibraryStore.visible` 与一个 `open` 事件 |
| N4 | 与现有层级一致 | z-index 高于画布与工作区工具条（5），低于浮动面板（1001）与设置弹窗 |

### 3.3 不在本次范围

- 不做右侧 Agent 面板的对称入口。
- 不做悬停自动打开（用户已明确选择「显示按钮，点击才打开」）。
- 不做停靠/浮层切换、宽度记忆等面板自身功能调整。
- 不改左下工具条与画布控制条里的素材库按钮。
- 不做触屏适配（触屏无 hover，入口不可见；现有入口仍可用）。
- 不做设置项开关。

### 3.4 边界约定

- 面板打开时入口 `v-if` 不渲染，不保留占位，不给隐藏元素留 tab 焦点。
- 触发区竖直居中按视口高度计算；窗口缩放时随 `position: fixed` 自动跟随，无需重算。
- 项目加载遮罩（`workspacePage` 的 `inert`）期间入口不可交互。
- 设置弹窗打开时被遮罩覆盖，不额外处理。
- 按钮显示后指针从热区移到按钮不会消失：热区（0–12px）与按钮（8–44px）在 8–12px 重叠，中间无空隙；同时保留 160ms 收起缓冲防抖。
- 鼠标在热区内快速划过也会短暂闪现按钮——这是悬停入口的固有行为，接受。
- 文档面板激活且素材库关闭时，文件树从视口 x=0 开始，居中热区会盖住文件树左缘约 8px 的点击与滚轮。热区宽度是用户明确选定值，本次接受此降级，不改宽度。
- 同一位置在画布上同样会吞掉热区范围内的 `pointerdown`/`wheel`/`contextmenu`：贴左缘的滚轮缩放、右键菜单在这一小条内失效，同样接受。
- 指针进入热区会让画布收到 `pointerleave`（`pointerInCanvas` 置 false、`pointerPosition` 清空），那一瞬间自动平移为 0、快捷键新建节点回落到画布中心；移出后恢复，接受。
- 打开面板后焦点交给素材库内容根节点；关闭面板后不把焦点还给已消失的入口（入口需悬停才出现），焦点留在 body，属已知限制。
- 按钮带 160ms 收起缓冲、160ms 过渡，完全消失约 0.32s。

> 后续调整（2026-11-02 13:43）：用户实测「移过去大概率又消失、点不到，判定区域太小」。热区由 12×160 放大到 40×240，收起缓冲 160ms 放宽到 400ms；按钮尺寸与位置不变。热区加宽后，左侧 40px 竖条内的画布/文件树点击与滚轮会被截获（已知降级，用户接受）。
>
> 最终调整（2026-11-02 13:45）：用户要求「打开素材库做成常驻式」。打开入口不再悬停显隐，改为左边缘、竖直居中的 36px 圆形按钮常驻显示；素材库打开时仍整体不渲染。热区、收起缓冲、窗口失焦/移出等悬停逻辑全部移除；右侧关闭入口继续保持悬停。常驻按钮占用左侧 8–44px 区域，画布上该区域的点击会被按钮拦截（可见控件，接受）。

## 4. 需求难度与风险

| 项目 | 评估 |
| --- | --- |
| 难度 | 低。新增一个约 120 行的无状态展示组件，在 `workspace/index.vue` 挂载并接线到现有 `assetLibraryStore.visible` |
| 风险 1 | 热区与画布手势冲突 → 热区仅 12px 且 `pointer-events` 只作用于该条，画布其余区域不受影响；拖拽节点越过左边缘时可能触发悬停，但不会打开面板（需点击），可接受 |
| 风险 2 | 鼠标在热区与按钮间移动导致闪烁 → 两者区域重叠 + 160ms 收起缓冲 |
| 风险 3 | 面板打开后按钮残留 → 入口渲染条件直接绑定 `assetLibraryStore.visible` |
| 风险 4 | 文档面板激活时入口层级错位 → 组件挂在工作区根节点、`position: fixed`，与激活面板无关 |

## 5. 验收标准

1. 素材库关闭时，鼠标贴到窗口左边缘竖直居中区域，圆形文件夹按钮滑入出现；向上、向下、向右移开鼠标后，按钮在约 0.16s 内开始收起、约 0.32s 完全消失。
2. 点击按钮，素材库按上次的停靠/浮层状态打开；打开后悬停左边缘不再出现按钮。
3. 用面板右上角关闭按钮关闭素材库后，悬停入口恢复可用。
4. 切换到文档面板，悬停入口同样可用；打开/关闭素材库行为一致。
5. 面板打开状态下拖动窗口缩放、切换面板，按钮不残留、不重复。
6. 鼠标在画布中部、节点上、左下工具条、左上菜单操作时，入口不出现、不拦截点击。
7. 键盘 Tab 可聚焦到按钮并显示，Enter 打开素材库。

## 6. 评审意见

子 Agent 初评（2026-11-02 12:52）：需求方向与边界成立，结论「修改后通过」。主要意见已并入 §3.4 边界约定与 §5 验收：

- 热区必须同时监听离开事件（否则从热区竖直/斜向移出时按钮永久停留）——需求 R2 原文已覆盖，实现已补。
- 「鼠标移出窗口」的收起方式需明确（macOS 不触发 window blur）——已写入方案。
- 热区与文档面板文件树左缘重叠——接受为已知降级。
- 验收时间应与「缓冲 + 过渡」一致——已改为约 0.32s 完全消失。
