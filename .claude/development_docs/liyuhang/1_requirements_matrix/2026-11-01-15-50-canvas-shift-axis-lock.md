# 需求矩阵：画布拖动按住 Shift 单轴锁定

- 时间：2026-11-01 15:50
- 提出人：用户
- 状态：已与用户确认

## 1. 需求背景

画布基于 `@vue-flow/core@1.48.2`，节点的拖动完全由 Vue Flow 内部 `useDrag` 处理：按下后超过 8px 阈值开始拖动，之后两轴同时跟随鼠标。用户在整理画布、把节点对齐成一行/一列时，只能靠放大画布肉眼对齐，或者开着 16px 网格吸附逐步挪，效率低且容易错位。

主流画布/设计工具（Figma、Sketch、Illustrator、多数节点编辑器）都支持「拖动时按住 Shift 只沿水平或垂直方向移动」，即单轴锁定。当前画布的 Shift 在拖动中没有被占用（拖动复制是 Alt、连边复制是 Alt+⌘），可以安全复用。

## 2. 需求目标

1. 拖动节点时按住 Shift，节点只沿一个轴移动，另一轴坐标保持在拖动起点。
2. 不改变现有拖动、网格吸附、拖动复制、分组吸附/重新归属等行为；不按 Shift 时完全维持现状。
3. 不引入新的设置项与视觉元素。

## 3. 需求描述

### 3.1 功能需求

| 编号 | 需求 | 优先级 | 说明 |
| --- | --- | --- | --- |
| R1 | Shift 单轴锁定 | P0 | 拖动节点过程中按住 Shift，只沿主轴移动，另一轴固定在拖动起点坐标 |
| R2 | 动态主轴 | P0 | 每次移动比较「相对拖动起点的水平位移 |dx| 与垂直位移 |dy|」，大者为主轴；拖动中途跨越对角线会切换主轴（与 Figma 一致） |
| R3 | 起点为锚 | P0 | 锚点固定为这次拖动开始时节点的原始坐标（按下鼠标后、超过拖动阈值前），不随按下 Shift 的时刻变化；中途按下 Shift 时被锁的那一轴会按设计弹回起点，另一轴保持当前位置 |
| R4 | 按住/松开即时生效 | P0 | 拖动中任意时刻按下 Shift 即锁定、松开即恢复自由；实现上以「下一次指针移动」为生效时机，指针完全静止时节点位置不变（见边界表） |
| R5 | 覆盖所有节点整体移动 | P0 | 单节点拖动、多选后拖其中一个、拖动多选包围框、分组连同子节点，统一生效 |
| R6 | 与网格吸附叠加 | P1 | 锁定轴保持拖动起点原值，不重新吸附；自由轴照常按 16px 网格吸附（若开关开启） |
| R7 | 与拖动复制叠加 | P1 | Shift+Alt（或 Shift+Alt+⌘）同时按住时，副本仍然锁轴移动；两个修饰键互不吞掉 |
| R8 | 无视觉提示 | P2 | 不加参考线、不改光标，靠移动本身反馈 |

### 3.2 非功能需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| N1 | 不打断撤销历史 | 一次拖动仍然只产生一条撤销记录（沿用 Vue Flow 的 dragStart/dragStop 分组） |
| N2 | 性能 | 每帧只多一次位置校正，不引入额外 DOM 监听或渲染层 |
| N3 | 可维护性 | 轴判定与坐标锁定抽成纯函数，可单测；画布层只做接线 |

### 3.3 不在本次范围

- 分组缩放手柄（改宽高）不锁轴；如需方向约束后续单独做。
- 框选矩形绘制不锁轴。
- 拖动连线、节点内部滑杆/画布小地图等交互不变。
- 不开放快捷键改键（固定 Shift，不进设置页）。
- 不做触屏适配（触屏没有 Shift 键，行为自然不生效）。

### 3.4 边界约定

- 按住 Shift 但指针完全静止时，节点不会立即弹到锁定轴；继续移动指针即生效。松手时以最后一次移动的位置落点。
- 拖入/拖出分组后，`finishGroupDrag` 会把绝对坐标吸附到网格并可能重新计算组尺寸，锁定轴最多偏离 8px——换组吸附优先于轴锁。
- Shift 固定用于轴锁：若用户把「节点复制 / 创建副本 / 画布平移」手动改成 Shift，会出现与轴锁同时触发、或抓手模式导致节点不可拖的情况；本次不做快捷键校验拦截，只记录优先级为「轴锁与手势各自判定」。

## 4. 需求难度与风险

| 项目 | 评估 |
| --- | --- |
| 难度 | 低。Vue Flow 没有内置轴锁，但节点拖动会派发 `nodeDragStart/nodeDrag/nodeDragStop`，可在宿主层校正坐标 |
| 风险 1 | 校正写回与 Vue Flow 内部拖动状态可能互相覆盖 → 需要每帧校正，并以拖动起点为基准，不能依赖上一帧位置 |
| 风险 2 | 分组的子节点不在拖动列表里（跟随父节点移动）→ 校正父节点相对坐标即可，不能逐个改子节点 |
| 风险 3 | 拖动复制的原节点每帧被还原，副本跟随原节点位置 → 校正必须排在 `dragCopy.update()` 之前 |
| 风险 4 | 拖动中途切换主轴会「跳」一下（另一轴弹回起点）→ 这是主流工具的既定行为，用户已确认 |

## 5. 验收标准

1. 选中一个节点，按住 Shift 向右拖：只横向移动，纵向坐标与拖动前一致；向下拖只纵向移动。
2. 拖动中先横后竖越过对角线，主轴切换为竖向，节点横向坐标回到起点。
3. 拖动中按下/松开 Shift，锁定立即生效/取消，节点不会被瞬移到鼠标另一轴位置之外的异常坐标。
4. 多选 3 个节点拖动、拖多选包围框、拖分组，均保持相对位置并只沿主轴移动。
5. Shift+Alt 拖动复制：副本锁轴移动，松手后原节点回到原位、副本落在主轴方向上。
6. 不按 Shift 的拖动、网格吸附、分组重新归属、撤销/重做与改动前一致。
