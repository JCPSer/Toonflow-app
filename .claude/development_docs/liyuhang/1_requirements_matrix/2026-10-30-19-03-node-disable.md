## 1. 需求背景

用户希望把画布上「不再需要的初级素材节点」屏蔽掉，让画布更清爽、也让 Agent 不再误用它们。语义接近 ComfyUI 的 mute（禁用）：节点留在画布上、可见但变灰，不参与执行、不可进行交互式操作、对 Agent 工具不可见，可随时解除。

## 2. 需求目标

给画布节点增加实例级「禁用」状态：节点保留在画布上、灰化呈现，不参与执行、不可进入交互式操作、不被 @ 引用、对 Agent 工具不可见；可随时解除，可撤销。

## 3. 非目标（本次不做）

- 不做级联禁用（分组级联、上下游联动），只作用于用户选中的非分组节点。
- 不做「隐藏」：节点仍在画布上占位、连线保留、Cmd+F 可搜到。
- 不改插件级 `.disabled`（整个节点类型停用），两者互不影响、不互相转换。
- **不堵 Agent 的直接文件读取**（`read/ls`、MCP `workspaceFiles` 读画布 JSON 仍能看到禁用节点）——它们是通用文件能力，过滤会让 read 结果与硬盘不一致。
- 不追溯历史：已发出的 Agent 消息里的既有引用不被改写；进行中的下游任务不中断，禁用只影响下一次运行。
- 不清理任何产物文件、素材库副本、节点输出。
- 不做禁用/删除互转，不做回收站。
- 不做跨窗口实时同步（另一个窗口刷新后生效）。
- 不扩大现有浮动工具栏的显示条件（见 R2 说明）。

## 6. 边界与风险

- **P0 级实现红线**：绝不能在 `getTargetSources` 过滤禁用节点。必须走「`getTargetValues` 保留占位 + `NodeInputValue.disabled`」契约，否则下游静默生成。
- **九条 Agent 路径**：任何一条漏过滤都等于「Agent 还能看到」。离线 mention（`mentionFiles.ts`）与 MCP 文档操作是独立实现，必须单独加过滤，测试逐条覆盖。
- **撤销快照是全局改动**：只写 `disabled === true` 避免 `undefined/false` 抖动；`restore()` 对删除后重建的节点必须用快照值覆盖 `nodeReferences`（后者是活引用）；不能让 `disabled` 落入 `index.vue:1119` 的只保存链。
- **分页游标**：`useCanvasTools.ts:31-32` 只 `deep:1` 监听；`canvasQueries` 的 revision 与 `queryMentionNodes` 的 revision（用 `nodes.length`）不会因禁用变化，禁用/解除后 Agent 翻页可能跳过或重复条目。需把禁用集合纳入 revision 签名。
- **连线变淡**：Vue Flow 的 `edgeClass` 是 `computed(() => edge.class(edge))`（`vue-flow-core.mjs:8900`），store 由 `reactive(state)` 创建、节点 `data` 是响应式的，因此在现有 `defaultEdgeOptions.class`（`index.vue:1806-1809`）里读 `sourceNode.data?.disabled` **会正常重算**；`toObject()` 会剥掉 `sourceNode/targetNode`，class 为函数时也不落盘。只需「class 函数读端点 `data.disabled` + CSS `stroke-opacity`」，**不要把字符串 class 写到 edge 对象上**（那会随保存落盘）。
- **不能改 Vue Flow 节点级开关**：`hidden/selectable/draggable/connectable/deletable` 会破坏框选、拖动、删除、搜索；禁用外观用 `nodeDisabled` 类 + 内容区覆盖层，不要复用 `readOnly`（它会隐藏标题栏删除并让文档挂载失效）。
- **覆盖层作用域**：只盖 `.contentCard` 与 top/bottom slot；`.nodeHandle`（`left/right: -12px`、`::before` 外扩 13px 的命中区）必须暴露，否则「调整连线」失效；标题栏是兄弟节点，覆盖层盖不到，其行为靠 `focusNode/editLabel/reloadNode` 守卫 + `v-if` 实现。
- **9 条 Agent 路径 → 7 组规则**：①前端只读查询→按 ID 抛错/扫描跳过；②@ 实时源→过滤；③mention 直读→抛错；④服务端离线 JSON→过滤；⑤自动上游注入→过滤；⑥节点函数→`list/call` 拒绝；⑦结构回执→过滤；⑧MCP 文档→拒绝；⑨文件直读→非目标。手工回归清单按这 9 行展开。
- **运行态**：`nodeBusy.ts` 需新增 `isNodeBusy`；批量禁用要在一次 `batch()` 内完成并汇总跳过项。
- **文档面板**：`syncDocumentNode`（`canvasMenu.vue:961-968`）直接写 `data.outputs`，禁用后应随面板关闭而停止；文档挂载的 4 个入口都要守卫。
- **分组节点**：`canvasGroup` 没有 target 端口与执行语义，不参与禁用。
- **数据无 schema（TS 侧有）**：`NodeData` 是封闭类型，必须加字段，否则类型检查失败；跨版本前进/回退不保证（与其它 data 字段一致）。
- **节点包需重建**：`nodeScaffold` 与 `nodeShared` 都会被打进每个节点 UMD，改任一都必须重建全部节点并同步部署。
- **可访问性**：半透明灰度下文字仍需可读；角标与 `aria-disabled` 要配套。
- **测试**：仓库没有测试框架，R6/R10 的验证要落成可执行的手工回归清单（按九条路径逐条给操作步骤）。
