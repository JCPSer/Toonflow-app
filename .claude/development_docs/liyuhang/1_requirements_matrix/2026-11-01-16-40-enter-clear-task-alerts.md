# 需求矩阵：空画布按 Enter 清除未读提醒

- 时间：2026-11-01 16:40
- 提出人：用户
- 状态：已与用户确认

## 1. 需求背景

节点完成/失败会在画布顶部弹出「N 个节点已完成 / N 个节点执行失败」的未读横幅（`taskAlertsStore.unread`，跨画布汇总），右上角有「全部忽略」按钮。用户希望不回鼠标、不在横幅上找按钮，直接在画布空白处按 Enter 就能清掉这批提醒。

画布当前的 Enter 没有任何绑定；输入框、节点搜索框、Agent 端口菜单各自使用 Enter，必须严格避开。

## 2. 需求目标

1. 画布聚焦且没有选中任何东西时，按 Enter 清除全部未读提醒（等同横幅的「全部忽略」）。
2. 作为画布快捷键可改键、可关闭，默认 Enter。
3. 有未读提醒才响应；没有提醒时 Enter 保持无操作，不拦截事件。
4. 不碰 Agent 提问横幅、桌面系统通知、瞬时 toast。

## 3. 需求描述

| 编号 | 需求 | 优先级 | 说明 |
| --- | --- | --- | --- |
| R1 | 新增画布快捷键「清除未读提醒」，默认 Enter | P0 | 进入「设置 → 常规配置 → 画布快捷键」的快捷键表，可改键，可设为「None」关闭 |
| R2 | 触发条件：画布聚焦、无选中 | P0 | 焦点在画布空白处（body/documentElement），而不是节点内的可聚焦元素；没有选中节点、连线，也没有在画布里选文字；焦点在 Agent 面板、输入框、按钮、可编辑区、对话框中不触发 |
| R3 | 只在有未读提醒时响应 | P0 | 有提醒才 `preventDefault` 并清空；没有提醒时什么都不做、不拦截 |
| R4 | 清除范围：全部未读 | P0 | 与横幅「全部忽略」一致：跨画布的全部未读一次清空 |
| R5 | 不影响其它提示 | P0 | Agent 提问横幅是「等你回答」的状态，不清；系统通知由 macOS 管理，应用无法清除；toast 自动消失，不处理 |
| R6 | 无额外视觉反馈 | P2 | 横幅消失即反馈，不弹 toast、不改光标 |

## 4. 不在本次范围

- 不清除 Agent 提问横幅（清掉会让人漏掉未回答的问题）。
- 不清除系统通知中心。
- 不新增鼠标手势或画布按钮。
- 不改变横幅「全部忽略」按钮的现有行为。

## 5. 需求难度与风险

| 项目 | 评估 |
| --- | --- |
| 难度 | 低。快捷键表是数据驱动的，新增一项后设置页自动出现；画布已有统一的键盘守卫（`updateCanvasKeys`） |
| 风险 1 | Enter 误触清掉还没看的提醒 → 可改键/可关闭；只在有未读时消费，且只在画布空选状态生效 |
| 风险 2 | 与输入框/节点搜索/Agent 端口菜单的 Enter 冲突 → 复用现有 `editing` 守卫与 `inCanvas` 判定；端口菜单焦点在按钮上，同样被 `editing` 挡住 |
| 风险 3 | 老配置里没有新键 → 设置读取时缺键回落到默认值，并对已保存的同键位做冲突回退（现有合并逻辑已覆盖） |
| 风险 4 | 与其它画布快捷键重复 → 设置页的冲突校验与保存时的回退逻辑沿用现有机制 |

## 6. 验收标准

1. 有未读提醒时，在画布空白处按 Enter：横幅消失，全部未读清空（包括其它画布产生的提醒）。
2. 没有未读提醒时按 Enter：无任何变化，Enter 不被拦截。
3. 选中节点/连线、或在节点里选中文字时按 Enter：不清除。
4. 在输入框、节点搜索框、Agent 端口菜单、Agent 面板、对话框、设置页里按 Enter：不清除。
5. 设置页能看到「清除未读提醒」，默认 Enter；改成其它键后按新键生效；设为「None」后 Enter 不再清除。
6. Agent 提问横幅、系统通知、toast 不受影响。

## 7. 评审意见

子 Agent 初评（2026-11-01 17:15）：

| 级别 | 意见 | 处理 |
| --- | --- | --- |
| P1 | 设置页冲突校验把 `None` 当按键比较，「框选节点」默认也是 `None`，导致新快捷键无法设为「None」关闭 | 已修：`shortcutConflicts` 中普通按键的 `None` 只表示关闭、不冲突；按住类手势之间都为 `None` 仍冲突（保留框选/平移互斥）；设置页与配置合并共用，补单测 |
| P2 | 分组名 `span[tabindex=0]` 有自己的 Enter（重命名），窗口捕获阶段会顺带清提醒 | 已修：clearAlerts 只接受焦点在 `body/documentElement`（画布空白处），节点内可聚焦元素不触发 |
| P3 | 小键盘 Enter（`NumpadEnter`）默认不命中 | 保留默认仅主键盘 Enter，写入已知限制；用户可自行加绑 |
| P3 | 浮层打开且焦点回到 body 时仍算画布聚焦 | 概率低，保留现状并写入已知限制 |
| P3 | 文档写的设置路径与实际不符 | 已改为「设置 → 常规配置 → 画布快捷键」 |
