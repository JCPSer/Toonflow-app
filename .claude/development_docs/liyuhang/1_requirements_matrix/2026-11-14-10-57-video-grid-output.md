# 需求矩阵：视频节点宫格图输出端口

- 时间：2026-11-14 10:57
- 状态：待评审

## 1. 需求背景

视频节点（「视频」与「视频生成」共用 `frameOutput` 模块）目前只能把首帧、尾帧作为 IMAGE 端口输出给下游。做连续镜头时，下游拿到的是一张静态图，缺少上一段视频的整体场景、人物状态信息，生成下一段时容易出现场景不一致。

节点里已有「查看视频」宫格（`inspect/contact-4.jpg`），但它是 Agent 查看用的临时产物：写在 `inspect/` 子目录、视频一变就清、卸载即删，且明确声明「不是节点输出」，无法接线。

## 2. 需求目标

给两个视频节点增加一个「宫格输出」IMAGE 端口，把当前视频的 2×2 宫格图作为节点输出，可连到下游图片/视频生成节点作为场景参考，并复用首/尾帧已有的开关、自动重抽、工具与错误处理机制。

## 3. 需求矩阵

| 编号 | 需求描述 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | 两个视频节点各新增一个 IMAGE 源端口 `gridFrame`，标签「宫格输出」；文件固定为 `assets/<nodeId>/frame-grid.jpg`，与 `frame-first.jpg`/`frame-last.jpg` 同级，**不放在 `inspect/`**（避免被查看产物的清理逻辑删除） | P0 | 低 | 与 inspect 混用目录会被卸载清理误删 |
| R2 | 宫格规格固定 2×2：与现有 `gridCell`/`gridFilter` 一致，单格长边 512、等比缩放后黑边补边、不叠序号或时间码；4 格采样点与现有宫格算法一致（`(i+0.5)×时长/5`，即 10%/30%/50%/70%） | P0 | 低 | 与「查看视频」宫格必须同源，否则两处画面口径不一致 |
| R3 | 行为与首/尾帧完全对齐：开启即抽帧并回填；视频替换/重新生成后依次重抽（首帧→尾帧→宫格）；关闭时移除端口并统计断开连线数；无视频时先建端口返回 pending=no-video；抽帧失败按路报错、不影响另外两路 | P0 | 中 | `errors`/`controllers`/`epochs` 字面量会因类型扩展直接报错；真正会静默漏掉的是 `setFrameError` 的汇总、`clear()` 的错误清理、`runJob` 收尾判断这三处 |
| R4 | Agent 工具 `setFrameOutputs` 增加 `grid` 参数，返回值结构与 `first`/`last` 一致（enabled/handleId/path/pending/pendingReason/error/removedEdges） | P0 | 低 | 描述不更新会让 Agent 不知道可以开 |
| R5 | 输出菜单增加第三行「宫格输出」，勾选式开关，带缩略图；「重新抽取」对三路一起生效；busy 时禁用 | P1 | 低 | 宫格整体比例随视频（横屏 1024×576、竖屏 576×1024），缩略图不能用 cover，否则竖屏只剩中间一条 |
| R6 | 兼容旧数据：历史画布的 `frameOutputs` 没有 `grid` 字段，默认关闭；旧分享包/复制节点行为不变 | P0 | 低 | 无 |
| R7 | 短视频（可用帧不足 4 帧）不报错：ffmpeg 的 `fps` 滤镜会重复补齐，四格可能是重复画面；与「查看视频」宫格行为一致 | P1 | 低 | 已实测 ffmpeg 7.1 退出 0 且正常出图，不能按「未生成文件」处理 |
| R8 | 类型与构建：`@toonflow/node-video` 两个节点 typecheck 通过并重建 UMD，同步到运行目录 | P0 | 低 | 视频生成节点引用共享源码，漏建会出现两节点能力不一致 |
| R9 | 插件级全局开关：两个视频节点的插件配置各增加「允许 Agent 宫格查看」（字段 `agentGridInspect`，**默认关闭**）。关闭后不向 Agent 注册 `sampleFrames`，`captureFrame` 与 `setFrameOutputs` 保留；在插件设置中保存后**立即生效**，无需重开项目 | P0 | 中 | 工具注册目前只能在 setup 内完成，动态开关需要给节点框架补一个可选的注册入口（兼容旧节点） |

## 4. 不在本次范围

- 宫格格数可配置（4/9/16）——已确认固定 2×2。
- 把「查看视频」的 `sampleFrames` 改为复用这个输出端口（两者采样一致，但生命周期与目录不同，本次只共享纯函数）。
- 在宫格上烧录序号/时间码。
- 关闭 `captureFrame`（本次开关只针对宫格查看）。

## 5. 验收口径

1. 在「视频」节点勾选宫格输出 → 端口出现、菜单显示 2×2 缩略图（竖屏完整不裁切）、输出值可被下游读取。
2. 替换视频 → 首帧、尾帧、宫格依次重抽（宫格最后完成），内容更新。
3. 关闭宫格 → 端口移除，已连线断开并提示条数。
4. Agent 调用 `setFrameOutputs({grid:true})` → 返回 path；`connectNodes` 可连到下游。
5. 视频生成节点同样具备上述能力。
6. 插件设置里「允许 Agent 宫格查看」默认关闭：新装环境下 Agent 的工具列表里没有 `sampleFrames`；打开开关并保存后，当前画布的节点立刻可以用，无需重开项目。
7. 开关关闭不影响 `captureFrame`，Agent 仍能按时间点截单帧查看细节。
