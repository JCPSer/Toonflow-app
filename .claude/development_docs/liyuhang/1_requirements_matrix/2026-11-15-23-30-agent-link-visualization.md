# 需求矩阵：Agent 派发关系可视化

- 时间：2026-11-15 23:30
- 类型：新能力（可视化）
- 状态：待评审

## 1. 背景

画布 Agent 之间已经能派活，但谁派给谁、任务在排队还是运行，只能逐个打开面板看会话。用户要求用有向箭头把 A→B 的派发直观画出来。

## 2. 已确认的产品决策

| 决策 | 选择 |
| --- | --- |
| 生命周期 | 仅任务存在期间显示，不写入画布 JSON |
| 方向 | 派发 A→B 一根箭头；任务结束改为 B→A 的短暂回传脉冲 |
| 信息量 | 状态色（排队灰/运行蓝/完成绿/取消黄/失败红）+ 悬停摘要与状态 |
| 不互动 | 不新增点击交互，避免与画布选择/拖拽抢事件 |

## 3. 需求矩阵

| 编号 | 需求 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | 派发入队即出现 A→B 箭头，运行中虚线流动 | 高 | 中 | 中：坐标换算与响应式 |
| R2 | 任务结束箭头退场，B→A 回传脉冲保留约 1.6 秒并按结束状态着色 | 高 | 中 | 低 |
| R3 | 停止/取消时清掉排队箭头，运行中的箭头以取消色退场 | 高 | 低 | 低 |
| R4 | 悬停显示「A → B · 状态 · 任务摘要」 | 中 | 中 | 中：SVG 命中区与 tooltip 定位 |
| R5 | 不污染画布数据：不产生 Vue Flow 边、不触发保存、不参与删除/撤销 | 高 | 低 | 低 |
| R6 | 并发/排队多任务时每任务一根线，互不覆盖 | 中 | 低 | 低 |

## 4. 非目标

- 常驻关系图、历史派发记录、线的点击跳转。
- 跨画布/跨项目关系。
- 写入画布 JSON 或参与布局算法。

## 5. 关键约束

- 层位于画布之上、不拦截画布拖拽与选择；只有线本身接收悬停。
- 坐标必须跟随画布平移、缩放与节点拖动。
- 不新增保存字段，分享/导出不受影响。
