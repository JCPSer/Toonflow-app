# 需求矩阵：画布边缘自动平移（拖动节点/连线时）

- 记录时间：2026-10-29 08:50
- 来源：用户口述「节点拖动到画布边缘时现在没有辅助滑动画布的逻辑，希望加一个」

## 一、需求背景

画布面板（`apps/web/src/pages/workspace/panels/canvas/index.vue`）的 `<vue-flow>` 上，`auto-pan-on-node-drag` 与 `auto-pan-on-connect` 两个属性在初始提交里就被显式写死为 `false`。结果是：画布内容一旦铺满视口，用户拖动节点（或从端口往外拖连线）到画布边缘时画布纹丝不动，必须先松手、用中键/空格或滚动平移、再继续拖，一次成型的布局被打断成两段操作。窄面板（Agent 面板展开、素材库展开）时尤为明显，可视区更小。

## 二、需求目标

拖动元素接近画布可视边缘时，画布自动朝该方向平移，让元素可以一次性拖到当前视口之外的位置；平移期间元素始终跟随光标。

## 三、需求描述

| 编号 | 描述 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | 拖动节点（含多选、组节点及其子节点）靠近画布边缘时，画布自动平移；光标停在边缘不动也持续平移 | P0 | 低 | 低 |
| R2 | 从端口拖连线、光标靠近边缘时画布自动平移，连线终点跟随 | P0 | 低 | 中 |
| R3 | 平移手感可感知：热区约 40px 线性加速，峰值 20px/帧 | P1 | 低 | 低 |
| R4 | 不做视觉提示（边缘不加光晕/箭头），与 Figma 一致 | P2 | 低 | 无 |
| R5 | 平移不得改变既有交互：中键平移、抓手模式、滚轮/捏合缩放、组内穿透探测、右键菜单、框选、吸附 | P0 | 低 | 中 |
| R6 | 指针滑出画布（进入右侧 Agent 面板/左侧素材库）即停止平移，回到画布内恢复 | P0 | 低 | 低 |
| R7 | 节点拖动起步距离 1px → 4px，避免贴边点击节点时手抖 1px 就触发拖动并让画布滑走 | P1 | 低 | 低 |

### 非目标

- 不实现框选拖拽时的自动平移（Vue Flow 内置不提供，成本远高于收益）。
- 不实现平移边界（`translateExtent`），与现有中键平移一致，画布可无限延伸。
- 不改动侧边面板（Agent 对话、素材库）的展开/收起逻辑。

## 四、实现约束

画布面板宽度 = `100% - agentWidth - assetWidth`，`.vue-flow` 矩形与实际可视区一致，因此热区不会算到侧栏里。但 Vue Flow 的 `calcAutoPan` **不夹取坐标**：光标越过容器右边界进入侧栏后，速度持续饱和在最高值（20px/帧，约 1200px/s），节点被侧栏挡住仍在滑——所以必须额外做 R6 的越界停速，不能只靠容器矩形。
