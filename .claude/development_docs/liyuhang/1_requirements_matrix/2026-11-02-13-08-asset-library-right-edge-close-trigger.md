# 需求矩阵：素材库面板右边缘悬停关闭入口

- 时间：2026-11-02 13:08
- 提出人：用户
- 状态：已与用户确认（grill-me 逐项确认）

## 1. 需求背景

素材库面板打开后，关闭入口只有面板标题栏右上角的 `×`（`floatingAssetLibrary.vue` 头部）。上一需求刚加了「左边缘悬停打开」入口，用户在打开面板后，鼠标通常在面板右边缘附近（尤其是面板停靠占宽 360px 时），希望在同一高度有一条对称的关闭入口：鼠标贴到面板右边缘外侧，出现圆形按钮，点击即把面板向左滑出关闭。

## 2. 需求目标

1. 素材库面板打开时，在面板最右侧竖直居中提供悬停关闭按钮；鼠标移开后消失。
2. 点击按钮关闭素材库（沿用现有 `visible = false` 与左滑收起动画）。
3. 与左侧打开入口视觉、交互对称：36px 圆形、160ms 悬停缓冲、160ms 过渡。
4. 停靠与浮层两种形态都生效，按钮始终跟随面板右边缘。
5. 不影响面板内容点击、右边缘拖拽缩放、画布交互。

## 3. 需求描述

### 3.1 功能需求

| 编号 | 需求 | 优先级 | 说明 |
| --- | --- | --- | --- |
| R1 | 悬停出现 | P0 | 指针进入「面板右边缘外侧 12px × 竖直居中 160px」热区时，圆形按钮从面板边缘向外滑入淡入 |
| R2 | 移开消失 | P0 | 指针离开热区与按钮（160ms 缓冲）后按钮滑回淡出；窗口失焦同样收起 |
| R3 | 点击关闭 | P0 | 点击按钮把素材库 `visible` 置 false，面板按现有 `slide-from="left"` 动画向左滑出 |
| R4 | 跟随面板 | P0 | 按钮挂靠在面板元素上（面板内的绝对定位子元素），停靠/浮层、拖动、缩放时始终贴着右边缘竖直居中 |
| R5 | 空间不足回退 | P1 | 面板右边缘距视口右侧不足 52px 时（浮层拖到屏幕右缘），按钮翻到面板内侧右边缘 8px，仍可点击；热区保持在面板外侧 |
| R6 | 形态 | P0 | 36px 圆形，左箭头图标（`IconChevronLeft`），玻璃底 + 1px 描边，与左侧打开入口一致 |
| R7 | 无障碍 | P1 | `aria-label="关闭素材库"`、title、`aria-controls="assetLibraryPanel"`；键盘 Tab 聚焦时显示，Enter 关闭 |
| R8 | 两面板通用 | P0 | 画布与文档面板激活时都生效（属于素材库面板自身） |

### 3.2 非功能需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| N1 | 不挡面板 | 常态下按钮与热区都在面板边框外侧，不遮挡内容、不与右边缘 5px 缩放热区重叠；回退态（R5）按钮会覆盖面板右缘内侧一小块内容，见 §3.4 |
| N2 | 不产生常驻监听 | 只在面板组件内部用 DOM 事件；不挂 window pointermove、不读画布状态 |
| N3 | 可维护性 | 独立小组件，只接收 `open/visible` 状态并由父级关闭面板；复用左侧入口的悬停状态机写法 |
| N4 | 层级 | 面板 `aside` 本身 z-index 1001，按钮作为其子元素自然高于画布与工具条，无需额外层级 |

### 3.3 不在本次范围

- 不做拖拽把手式关闭（已确认点击关闭）。
- 不给 Agent 面板加对称入口。
- 不改面板标题栏的 `×` 关闭按钮。
- 不改停靠/浮层切换、宽高记忆。
- 不做触屏适配（触屏没有 hover；标题栏 `×` 仍可用）。

### 3.4 边界约定

- 热区只占面板外侧 12px，**不覆盖面板内部**：面板最右 5px 是缩放热区，不抢它的指针事件；面板内容区点击、滚轮不受影响。
- 热区所在的「面板外侧 12px 竖条」会截获该范围内的画布/文档点击与滚轮（`pointerdown`/`wheel`/`contextmenu`），与左侧入口的已知降级相同，接受。
- 指针从热区移到按钮（两者在 8–12px 重叠）不会闪烁；160ms 缓冲。
- 窗口右缘空间不足时（`rect.right + 52 > innerWidth`）按钮翻到面板内侧；热区仍在面板外侧，指针穿过面板边框进入按钮时靠 160ms 缓冲衔接。
- 面板关闭后整块 `v-show` 隐藏，按钮与热区一起消失；左边缘打开入口同时恢复。
- 按钮聚焦时鼠标移开不隐藏；窗口失焦时先 `blur()` 再隐藏，避免不可见焦点。
- 关闭后焦点随面板隐藏落回 body（与点击标题栏 `×` 的现有行为一致），不额外处理。

> 后续调整（2026-11-02 13:43）：用户实测两个入口都「移过去大概率又消失、点不到，判定区域太小」。热区由 12×160 放大到 40×240（仍在面板外侧），共用状态机的收起缓冲 160ms 放宽到 400ms；按钮尺寸与位置不变。

## 4. 需求难度与风险

| 项目 | 评估 |
| --- | --- |
| 难度 | 低。新增约 120 行展示组件，作为 `floatingAssetLibrary` 默认 slot 的第二个根节点渲染进 `aside`，天然跟随面板定位 |
| 风险 1 | 与右侧缩放热区抢事件 → 热区与按钮全部放在面板外侧，互不重叠 |
| 风险 2 | 浮层贴屏幕右缘时按钮出屏 → R5 回退到内侧 |
| 风险 3 | 面板拖动/缩放的定位不同步 → 绝对定位相对 `aside`，无需监听几何变化 |
| 风险 4 | 与左侧入口状态冲突 → 二者互斥：素材库可见时左入口不渲染 |

## 5. 验收标准

1. 素材库打开（停靠或浮层），鼠标贴到面板右边缘外侧竖直居中，圆形左箭头按钮滑入；移开后约 0.32s 完全消失。
2. 点击按钮，素材库向左滑出关闭，左边缘打开入口恢复可用。
3. 拖动浮层面板、调整停靠宽度时，按钮始终贴在右边缘竖直居中。
4. 浮层面板拖到贴近屏幕右缘时，按钮翻到面板内侧仍可点击。
5. 面板内容点击、滚轮、右边缘拖拽缩放不被热区或按钮拦截（R5 回退态下按钮压在面板内侧右缘 8–44px 除外）。
6. 键盘 Tab 聚焦按钮时按钮显示，Enter 关闭素材库。

## 6. 评审意见

子 Agent 初评（2026-11-02 13:22）：**修改后通过**，无 P1，4 个 P2、若干 P3。主要意见已并入：

- N1 与 R5 关于「按钮是否在面板外侧」的表述矛盾 → N1 已改为「常态在外侧、回退态覆盖右缘内侧一小块」，验收 5 加回退态例外。
- 键盘聚焦路径也要重算回退 → 已写入方案 §3.3（`reveal()`）。
- 回退判定不得读受 transform 影响的 rect → 已改为读内联 `left/width`，并写入方案。
- i18n 约定 → 两个入口统一 `translate()`。
- 触屏隐形热区吞点击 → 补 `@media (hover: none)` 隐藏。
