# 需求矩阵：项目/画布下拉与素材库面板快捷键

- 时间：2026-11-03 16:07
- 提出人：liyuhang
- 状态：待评审

## 1. 需求矩阵

| 项目 | 内容 |
| --- | --- |
| 背景 | 项目下拉、画布下拉、素材库面板目前只能用鼠标点；逐帧核对与切画布操作频繁，来回移动指针成本高。用户希望像工具键（V/H）一样用单键唤起 |
| 目标 | 三个高频入口各有一个可配置的单键快捷键，按下直达、再按关闭、打开即能继续键盘输入 |
| 优先级 | P2（纯效率增强，不影响功能完整性） |
| 难度 | 低（现有 `canvasShortcuts` 已提供配置、录制、冲突检测与设置页 UI） |
| 风险 | 低；主要风险是裸键误触（在输入框、便签正文、弹窗里按 Q/W/E 触发了面板开关）与与现有快捷键冲突 |

### R1 项目下拉快捷键

- 描述：在画布视图按快捷键，打开/关闭左上角的「切换项目」下拉。**打开后不抢焦点**——焦点留在画布，保证再按同一个键能收起、按另一个键能切换；要搜索需手动点搜索框。
- 默认键：`Q`。
- 范围：仅画布视图（该项目下拉只在画布面板顶部存在）。

### R2 画布下拉快捷键

- 描述：在画布视图按快捷键，打开/关闭「切换画布」下拉；同样不抢焦点。
- 默认键：`W`。
- 范围：仅画布视图。
- 互斥：与 R1 同时只能开一个，按其中一个会关掉另一个。

### R3 素材库面板快捷键

- 描述：按快捷键打开/关闭素材库浮层面板；打开后焦点交给面板内容（与点击左边缘入口的现有行为一致）。
- 默认键：`E`。
- 范围：画布与文档视图都可用（素材库是工作区级面板）。

### R4 可配置与冲突处理

- 三个快捷键进入设置页「画布快捷键」列表：可录制/手填改键、**留空即取消绑定**（普通动作不用 None 语义）、参与现有冲突检测与「恢复默认」。
- 默认值 Q/W/E 与现有默认键（V/H/Tab/Enter/Space/Backspace/⌘ 组合等）不冲突。

### R5 误触防护

- 焦点在输入框、文本域、下拉、`contenteditable`（便签正文/节点编辑器）、滑块或对话框内时，三个快捷键都不触发。
- 例外：Q/W 只让位给文本类控件——焦点停在按钮上（例如刚点过下拉触发按钮）时不阻止，保证「点一下按钮再按键」可用；E 对所有控件（含按钮）设防，避免在表单里误开面板。
- 设置页打开时不触发（与现有画布快捷键一致）。
- 正在按住 Ctrl/Alt/Shift/⌘ 时不触发（避免抢走 ⌘Q 等系统组合）。

### R6 设置面板快捷键（追加）

- 描述：⌘, 打开/关闭设置面板；首页与工作区都能用。
- 默认键：写死 macOS 惯例 ⌘,（非 Mac 平台 Ctrl+,），**不进设置页、不可改键**（避免改掉后找不到设置入口）。
- 门禁：别家弹窗占着焦点时不抢；设置自己开着时允许关闭，但设置内再弹确认框时让给确认框。

## 2. 验收标准

1. 画布视图按 Q：项目下拉展开（焦点仍在画布）；再按 Q 收起。
2. 画布视图按 W：画布下拉展开（焦点仍在画布）；再按 W 收起；在 Q 打开时按 W，Q 收起、W 展开。
3. 画布/文档视图按 E：素材库打开；再按 E 关闭。
4. 在便签正文、搜索框、设置页、对话框里按 Q/W/E 不触发。
5. 设置页可把任一键改成别的键或留空取消绑定，改完立即生效；冲突时给出提示。
6. 首页/工作区按 ⌘,：设置打开；再按一次关闭；对话框打开时按 ⌘, 不抢。
