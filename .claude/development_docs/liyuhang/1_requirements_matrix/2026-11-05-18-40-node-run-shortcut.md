# 需求矩阵：⌘Enter 运行选中节点

- 时间：2026-11-05 18:40
- 提出人：liyuhang
- 状态：待评审

## 1. 需求矩阵

| 项目 | 内容 |
| --- | --- |
| 背景 | 生成节点要跑一次必须移到节点卡片点底部的「生成」按钮；连续调参试跑时手要在画布和节点之间来回移动 |
| 目标 | 选中节点后按 ⌘Enter 直接启动生成；与已有画布快捷键体系一致、可配置、可误触防护 |
| 优先级 | P2（效率增强） |
| 难度 | 中（节点包是独立 UMD，画布拿不到节点内部函数，需要新增跨包运行入口注册表） |
| 风险 | 中：误触可能启动付费生成；运行中重复触发可能重复扣费；输入框内触发与文本编辑习惯冲突 |

### R1 快捷键与作用对象

- 默认 `⌘Enter`（非 Mac 为 `Ctrl+Enter`），对当前选中的节点生效。
- 选中多个节点时，所有「可运行」的节点并行启动。
- 没有任何选中时提示「请先选中要运行的节点」。

### R2 生效节点范围

- 仅图片生成、视频生成、音频生成、文本这四类有「生成」主操作的节点。
- 其它节点（便签、图片/视频素材、帧分析、Agent 等）不响应；全部不可运行时提示。

### R3 运行中 / 禁用

- 正在运行的节点再次按快捷键：忽略，不停止、不重启。
- 已禁用节点：跳过。
- 上游被禁用的节点仍走节点自己的校验（提示上游禁用）。

### R4 焦点与误触防护

- 焦点在节点内的提示词/参数输入框时仍然生效（写完提示词直接 ⌘Enter）。
- 焦点在弹窗（设置、素材全屏、文本编辑弹窗）、Agent 面板、非画布区域时不生效。
- 画布未激活、设置面板打开时不生效；按键重复（按住）只触发一次。

### R5 可配置

- 进「设置 → 通用 → 画布快捷键」，字段名「运行选中节点」，默认 `⌘Enter`。
- 可录制改键、可清空取消绑定；参与现有冲突检测与恢复默认。
- 与「清除未读提醒」（裸 Enter）不冲突：修饰键匹配严格全等。

## 2. 验收标准

1. 选中一个图片生成节点按 ⌘Enter：开始生成，节点进入运行态。
2. 焦点在节点提示词输入框内按 ⌘Enter：同样开始生成，不会插入换行。
3. 框选多个生成节点按 ⌘Enter：全部并行开始。
4. 选中运行中的节点再按：不重启、不停止。
5. 选中便签/素材节点按 ⌘Enter：提示没有可运行的生成任务。
6. 设置页把快捷键清空后：⌘Enter 不再触发；改成其它组合后立即生效。
7. 打开设置对话框、或焦点在 Agent 面板输入框时按 ⌘Enter：不触发画布节点。
