# 需求矩阵：Agent 提问提示音

- 时间：2026-11-01 07:50
- 分支：`feat/exec-node`
- 提出人：用户

## 1. 需求背景

画布上的 Agent 节点调用 `askUser` 提问时，只会在画布顶部出现「N 个 Agent 正在等你回答」未读横幅（`agentNodePanel.vue` 上报，`canvas/index.vue` 渲染），没有任何声音。节点任务完成/失败已有「节点提示音」（WebAudio 合成双音），但提问不在这条提醒链路上，用户没盯着画布时容易错过。

代码现状核实：

- 全仓库 `notifyDesktop` 只有 `taskAlerts.ts` 一个调用方；Agent 提问不触发 macOS 系统通知。
- 提示音只在 `taskAlerts.flush()` 里播放，来源是节点任务事件 `toonflow:node-task`，且要求任务时长 ≥ 30 秒。
- 提问链路：`askUser` → 服务端 `question` 事件 → `conversation.vue` emit `question` → `agentNodePanel.onQuestion` → 未读横幅。

## 2. 需求目标

Agent 在画布节点里发起提问时，用户能听到与「完成/失败」区分得开的提示音；开关沿用现有节点提示音设置，不新增配置入口。

## 3. 需求描述

| 编号 | 需求 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | 画布 Agent 节点每次收到新提问时播放提示音，不依赖提问卡片是否可见 | P0 | 低 | 触发点选错会漏响/重复响 |
| R2 | 复用「节点提示音」三档开关（总是/仅后台/关闭），不新增配置项 | P0 | 低 | 与节点完成音的判定口径需一致 |
| R3 | 提问音单独设计（同音双击 880Hz），与完成上行双音、失败下行双音可区分 | P1 | 低 | 音量/音高辨识度需实听 |
| R4 | 1 秒内的多个提问只响一次，避免多节点/子 Agent 同时提问叠成噪音 | P1 | 低 | 多画布实例需要有全局合并 |
| R5 | 设置页文案同步说明提问也会响，关掉开关连提问一起静音 | P1 | 低 | 只改描述，不改结构 |
| R6 | 不覆盖主 Agent 面板、供应商调试对话的提问（用户确认只做画布 Agent 节点） | P1 | 低 | 范围外场景保持现状 |

## 4. 不在本次范围

- 不新增 macOS 系统通知；不改变未读横幅的出现/已读规则。
- 不为提问单独增加开关或音量设置。
- 不改服务端 `askUser` 协议与事件流。

## 5. 验收口径

1. 画布 Agent 节点提问 → 听到「叮叮」（880Hz 两下）；完成音仍是上行、失败音仍是下行。
2. 节点提示音设为「关闭」→ 提问不响；设为「仅后台」→ 前台不响、窗口失焦后响。
3. 两个节点在 1 秒内先后提问 → 只响一声，横幅仍显示两条。
4. 设置页说明能看到「或画布 Agent 提问时」。
5. 主 Agent 面板里提问不响（范围外，保持现状）。
