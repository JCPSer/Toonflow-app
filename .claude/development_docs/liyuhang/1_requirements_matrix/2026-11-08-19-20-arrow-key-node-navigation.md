# 需求矩阵：画布方向键选择相邻节点

- 时间：2026-11-08 19:20
- 提出人：liyuhang
- 状态：已实施（待人工验收）

## 1. 需求矩阵

| 项目 | 内容 |
| --- | --- |
| 背景 | 画布只能用鼠标点选节点；键盘用户要跨节点只能靠 ⌘F 搜索，逐个别点选很慢。方向键目前完全空闲（Vue Flow 的 `nodes-focusable`、`disable-keyboard-a11y` 均关闭，画布内只有节点搜索框、节点右键菜单会消费方向键） |
| 目标 | 用 ↑↓←→ 在画布节点间按空间关系移动选中，Shift 可追加选中；过程中目标节点自动居中，全程不碰鼠标 |
| 优先级 | P2（效率增强） |
| 难度 | 中低：导航几何可抽成纯函数并单测；接入点在既有 `updateCanvasKeys`，可复用现有输入框/弹窗/面板守卫 |
| 风险 | 中低：方向键若在输入框、弹窗、Agent 面板或节点右键菜单内被误拦截会破坏文本操作；分组节点是大块背景，参与导航会频繁误选 |

### R1 方向键语义

- 只切换选中，不移动节点位置（移动仍交给鼠标拖动）。
- 裸方向键：把当前选区替换为一个节点（单选）。
- Shift+方向键：保留当前选区并追加目标节点。
- 带 ⌘/Ctrl/Alt 的方向键不处理，交给系统与控件。

### R2 目标节点的选取规则

- 有选中时：以**选区外接框中心**为起点，在按键方向 ±45° 锥形范围内，取"中心距离 + 横向偏移"最小者。
- 无选中时：取**视口中心**最近的节点（按到节点矩形的最短距离），选中它作为起点。
- 同分时依次比较：横向偏移、中心距离、节点 id（保证结果稳定）。
- 分组节点（`canvasGroup`）、隐藏节点、不可选节点不参与导航；已选中的节点不作为目标（否则原地打转）。

### R3 视口行为

- 每次成功导航都把目标节点中心移到视口中心，缩放比例保持不变（`setCenter` + 当前 zoom，180ms 动画）。
- 没有可去的节点时不移动视图、不改选区、不吞按键。

### R4 生效语境

- 只在画布语境生效：焦点在画布空白或节点上。
- 输入框、下拉、弹窗、节点提示词展开编辑框、Agent 面板内不生效。
- 节点内部控件（按钮、裁剪区、3D 场景等，它们自己用方向键）整体让位；画布工具条按钮不在节点内，点完仍可导航。
- 输入法组合中不触发；长按可连续走（导航属于连续操作，允许 repeat）。

### R5 可配置性

- 写死方向键，不进入「设置 → 画布快捷键」，不参与录制与冲突检测（与 Enter 重命名一致）。

## 2. 验收标准

1. 点击任一节点后按 →：选中其右侧最近的节点，且该节点居中。
2. 无任何选中时按 ↓：选中视口中心附近最近的节点。
3. 按住 Shift 连按方向键：选区逐步扩大，视图跟随最后一个目标。
4. 多选后用裸方向键：从整个选区外接框出发跳一个节点，并变为单选。
5. 分组背景不会被方向键选中；分组内的普通节点可以。
6. 焦点在节点提示词输入框、设置弹窗、Agent 面板消息区时按方向键：不改变画布选区。
7. 边缘节点按朝外方向键：选区不变、无报错。
8. 输入法组合中按方向键：不触发导航。
