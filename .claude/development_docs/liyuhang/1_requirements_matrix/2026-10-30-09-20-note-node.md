# 需求矩阵：便签节点

- 时间：2026-10-30 09:20（09:50 按首轮初审修订）
- 提出人：liyuhang
- 模块：画布节点（新增节点插件包 `packages/nodes/noteNode`）
- 代码基线：`0e5fda5` + 未提交的分组贴合 / 输入历史两轮改动

## 1. 需求背景

画布上现有的文本节点（`remote-textNode`）承担了两件事：承载文本、以及调用 LLM 生成文本。用户需要一种只做“说明/便签”的节点：不调用模型、不做数据流，像便签一样直接写、能换背景色与字色，用来在复杂流程图上写旁注、待办、设定备忘。

仓库现状（已核实）：没有任何便签/注释类节点；节点是独立 UMD 插件包（`packages/nodes/*`，类型 `remote-<name>`），由文件系统发现注册，新增节点不改后端校验；节点外壳为 `packages/nodeScaffold/src/nodeSkeleton.vue`；画布没有 NodeResizer，手动缩放需自行实现（参考 `components/groupNode.vue`：pointer capture + `batchCanvasHistory` + 手写 `node.dimensions` + 松手吸附）。

## 2. 需求目标

新增一种独立的画布节点“便签”，满足：便签式外观、纯文本随手编辑、无 LLM 调用、无端口不可连线、背景色与字体色可配、可拖拽调尺寸、随画布保存/撤销/复制/删除/分组正常工作。

非目标：不做富文本（Markdown 渲染、粗斜体、对齐）、不做字号档位、不做 Agent 读写、不进素材库/文档面板、不做主题联动色板。

## 4. 已确认决策

| 议题 | 结论 |
| --- | --- |
| 数据流 | 完全独立，不可连线 |
| 颜色 | 预设色板 + 字色独立，固定色板不随主题 |
| 正文 | 节点内直接编辑，纯文本，不做 Markdown 渲染 |
| 编辑入口 | 双击进入编辑 |
| 尺寸 | 可拖拽调大小 + 内容内部滚动 |
| 标题栏 | 保留细标题栏 |
| 文字样式 | 只开放字色 |
| 联动 | 与 Agent/素材库/文档完全隔离 |
| 存储 | 正文内联 `node.data`，配色写 `node.style` |
| 换色入口 | 选中时顶栏色块 |
| 撤销 | 颜色可撤销（存 style）；正文不进画布撤销，用输入框原生撤销 |

## 5. 已确认的实现口径（2026-10-30 09:30 用户回复“可以”）

1. 节点技术名 `noteNode`、显示名“便签”、默认标题“便签”。
2. 顶栏（浮动工具栏）只放背景色块 + 字色下拉；标题栏的刷新/删除按钮保留（删除需要）。
3. 默认尺寸 320×240；最小尺寸按初审上调为 160×160（骨架卡片最小高度 100 + 标题栏约 28，120 会溢出）；正文 14px / 行高 1.6。
4. 空便签显示占位提示“双击输入便签…”。
5. 不做 i18n（节点包本身不接入多语言，显示名为硬编码中文）。

## 6. 需求边界

- 不修改 textNode；不新增后端路由、不新增节点类型白名单校验。
- 不接入 Canvas 文档面板、素材库、Agent 引用（`mentionSources`）、`nodeTools`。
- 不提供自定义取色器（自由 hex）、不做 Markdown/富文本、不做字号/对齐。
- 不要求“组内缩放自动扩组”，组尺寸在下一次拖动/整理时贴合。

## 8. 子代理初审记录（2026-10-30 09:45）

结论：方向可行，首版不可通过。已按意见修订，要点：

- **R10 事实纠正**：画布历史刻意不记录 `data`（`useCanvasHistory.ts:20,34-37`；`canvas/index.vue:1103-1109` 中 `data` 变化只保存不记历史），原“文本一步撤销”不可实现 → 改为“配色写 `style`（`style` 属非运行态字段，变化会走 `scheduleCanvasChange → record`，`canvas/index.vue:1064-1075`），正文不进历史”。
- **R5 上调为高风险**：新建节点只写 `data.label`（`nodeMenu.vue:425`），骨架固定 `width:220px`（`nodeSkeleton.vue:711`）且卡片最小高度 100（`:282`），默认尺寸不会自动出现、120 高会溢出 → 方案要求包内覆盖 `width/height:100%`、挂载写默认 `style`、最小高度改 160；缩放必须用 `batchCanvasHistory` 包住整个拖拽，否则每帧一条快照（`groupNode.vue:147-161`）。
- **R4 上调风险**：骨架根节点双击 `focusNode` 缩放视口（`nodeSkeleton.vue:4`）、画布根双击开菜单（`canvas/index.vue:7`）、`panOnScroll` 为 true（`:44`）→ 补“不缩放视口/不弹菜单/滚轮只滚正文”验收。
- **R6/R9/R12 可测化与事实修正**：`data` 会被骨架写入 `handles`/`outputs`（`nodeSkeleton.vue:683-689`），验收改看 `noteText`；菜单排序只对未自定义菜单生效（`apps/server/src/lib/nodeMenu.ts:54-73`）。
- **新增 R15**：正文若逐键写 `data` 会触发整张画布防抖保存，改为退出编辑时一次写入。
- 事实纠正：`groupNode` 缩放不只是“写 style”，还依赖 pointer capture、`batchCanvasHistory`、手动同步 `dimensions`、松手吸附；画布菜单图标来自组件 `defineOptions.icon`，设置页图标是另一份静态表。
