# 需求矩阵：项目快速切换 + 跨项目粘贴带文件 + 画布 Esc 退出确认

- 记录时间：2026-10-29 10:30
- 用户：liyuhang
- 关联模块：`apps/web/src/pages/workspace/**`、`apps/web/src/pages/workspace/panels/canvas/**`、`packages/nodeScaffold/src/nodeSkeleton.vue`、`apps/server/src/routes/workspaces/files/**`

## 一、需求背景

工作区（`/workspace`）目前只有「退出项目」一个出口：从画布左上角的项目名只能改名，想换项目必须回首页重新选择，链路长且打断心流。另外跨项目粘贴节点时，一旦节点输出引用了项目内的素材文件，会被硬性拦截（「此节点引用工作区文件，不能跨项目粘贴」），用户无法把已经调好的节点复用到另一个项目。画布也没有 Esc 快捷键，误按后无处可退。

## 二、需求目标

1. 在画布左上角项目名旁提供常驻的项目切换入口，不离开工作区即可切换项目。
2. 跨项目粘贴时把节点引用的文件一并复制到目标项目，粘贴成功；不覆盖目标项目已有文件。
3. 画布内 Esc 可触发退出项目确认框，且不与既有的「取消选择 / 关闭弹层」冲突。

## 三、需求描述

### R1 项目名下拉切换（画布左上角）

| 项 | 内容 |
| --- | --- |
| 位置 | `canvasMenu.vue` 顶部：项目名输入框右侧、画布选择器左侧，加一个 `⌄` 箭头按钮 |
| 形态 | 点击箭头弹出下拉面板（`el-popover`），列出 `workspaceStore.projectList`；当前项目带勾选标记；列表按最近打开时间倒序；带搜索框（项目多时可用） |
| 与改名共存 | 项目名输入框行为不变（点击即编辑、Enter/失焦保存）；箭头是独立按钮，不触发展开改名 |
| 空列表 | `projectList` 只有当前项目时仍在列表中显示，避免点了没反应 |
| 视觉 | 复用画布选择器下拉的样式语言（同宽卡片、hover 高亮、勾选图标） |

### R2 切换时保存与拦截

| 项 | 内容 |
| --- | --- |
| 保存 | 切换前 `await flushSave()`，把当前画布与节点状态落盘；保存失败则不切换并提示 |
| 拦截 | 存在正在运行的节点时弹确认「有节点正在运行，切换项目会中断任务，是否继续」；取消则停在当前项目 |
| 运行判定 | 「正在运行」= 节点卡片 `busy` 为真（Agent 节点思考/运行、生成节点生成中、导出/转写等） |
| 失败处理 | 目标项目目录不存在（404）时提示「项目文件夹不存在」，并提供「重新选择文件夹」入口（与首页一致）或直接提示后不切换 |
| 切换后 | 画布/文档面板/素材库/Agent 面板按新目录重载，不得残留上一个项目的画布或会话 |

### R3 跨项目粘贴带文件

| 项 | 内容 |
| --- | --- |
| 现状 | `readClipboardNodes()` 检测到节点 `data.outputs` 中存在工作区相对路径（非 http/blob 等绝对地址）且源目录 ≠ 目标目录时直接抛错 |
| 期望 | 把检测到的文件从源项目复制到目标项目，改写节点数据里的引用路径后正常粘贴 |
| 冲突策略 | 同相对路径且内容相同 → 跳过复制（复用目标已有文件）；同路径但内容不同 → 复制为 `<原名>-<短id>.<扩展名>`，并把节点 `outputs.*.value.url` 改写为新路径；绝不覆盖目标项目已有文件 |
| 缺失文件 | 源文件已不存在 → 跳过该文件并保留原引用，粘贴继续，结束时汇总提示（不因单个文件阻断整体粘贴） |
| 反馈 | 成功后提示「已复制 N 个文件到当前项目」；无文件时不提示 |
| 范围 | 仅检测/复制 `data.outputs` 里的媒体文件引用（与现有拦截口径一致），不处理节点内其他自定义字段 |

### R4 画布 Esc 退出确认

| 项 | 内容 |
| --- | --- |
| 触发 | 当前面板为画布、无节点/边选中、无框选区域、焦点不在输入框/可编辑区、无下拉或弹层打开时，按 Esc 弹「是否退出当前项目并返回首页？」 |
| 优先级 | 有选区时第一次 Esc 只清空选择；再按一次才弹确认（沿用用户已确认的决策） |
| 已有 Esc 行为 | 已有弹层（画布选择器、节点菜单、Agent 端口菜单等）关闭优先，不得同时触发退出确认 |
| 复用 | 复用现有 `workspaceMenu` 的退出确认对话框与 `router.push("/home")` 流程，不重复实现 |

## 四、优先级与难度

| 需求 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- |
| R1 项目切换入口 | P0 | 中 | 中：切换会重挂载画布/文档/素材/Agent，需确认无残留订阅与误保存 |
| R2 切换保存与拦截 | P0 | 中 | 高：运行中节点被中断会丢进度，判定必须可靠（新增 busy 全局登记） |
| R3 跨项目粘贴带文件 | P0 | 高 | 高：需新增跨目录复制接口、内容比对与引用改写；写错路径会污染目标项目 |
| R4 Esc 退出确认 | P1 | 低 | 中：Esc 与已有弹层/选择行为冲突，容易误弹 |

## 五、非目标（本轮不做）

- 项目列表的「新建项目 / 打开其他项目」入口（仍需回首页），如需要可下一轮加。
- 项目列表条目上的重命名/移除（首页已有）。
- 跨项目复制素材库、角色库、技能等非节点输出引用。
- 跨项目粘贴时同步复制 `library` / `.toonflow` 等应用管理目录。

## 六、验收标准

1. 画布左上角点箭头 → 列出项目，点另一个项目 → 保存当前画布并切过去，画布、Agent 会话、素材库均为新项目内容。
2. 有节点在跑时点切换 → 出现确认框；取消后仍在原项目且任务继续。
3. A 项目复制一个引用了图片的节点，切到 B 项目粘贴 → 成功，图片在 B 项目可正常预览；B 项目原本的同名文件未被改动。
4. 画布空白处按 Esc → 出现退出确认；取消后留在画布；已有选中的节点时按 Esc 只清选择。
5. 输入框内按 Esc、弹层打开时按 Esc 不触发退出确认。
