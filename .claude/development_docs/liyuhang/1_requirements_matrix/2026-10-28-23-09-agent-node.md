# 需求矩阵：Agent 节点（画布内嵌 agent 会话）

- 记录时间：2026-10-28 23:09（23:50 按评审修订）
- 代码基线：`4e3d298`
- 用户原话：「我想加一个新节点……就是 agent 节点，该节点没有输出，有输入，也可以自己选 skill 技能」

## 一、需求背景

画布目前只有「素材/生成」类节点，多步流程必须回右侧主对话让 agent 操作，主对话与画布流程是两条线。用户要把 agent 本身变成节点：流程里放一个 Agent，接上游素材，给它任务，它自己干活（可建/改/删画布节点），产物留在画布上。

## 二、已确认决策（用户逐条选定）

| # | 决策点 | 结论 |
| --- | --- | --- |
| D1 | 输入语义 | 上游只当上下文，**不自动触发**；用户手动发消息才跑 |
| D2 | 会话归属 | 每个节点一个独立会话，互不串上下文，不出现在左侧历史列表 |
| D3 | 权限 | 与主对话同权：可建/连/改/删画布节点 |
| D4 | 技能 | 每轮临时选，沿用输入框 `/skill:名字`，不落节点配置 |
| D5 | 面板位置 | 画布层浮层，复用现有对话界面，**附在节点旁跟随**节点移动与缩放 |
| D6 | 面板数量 | 同一时刻只显示一个；单击节点开，点画布空白/其它节点/Esc 关 |
| D7 | 输入类型 | 全类型（文本/图片/视频/音频/文件） |
| D8 | 上游注入 | 每次发消息自动作为引用带上 |
| D9 | 模型 | 跟随全局设置，节点面板不提供模型修改入口 |
| D10 | 复制 | 复制节点/画布 → 新节点拿到**分叉**的新会话，不共享 |
| D11 | 删除节点 | 会话文件**等撤销窗口过后**再删（可撤销） |
| D12 | 状态 | 待开始 / 等待输入 / 理解中 / 运行中，四态，不加失败态 |
| D13 | 关闭面板 | 正在跑的那轮**继续跑**，只是看不见；不承诺跨刷新/跨标签重连 |
| D14 | 节点面板内分支按钮 | 分叉出**另一个 Agent 节点**（原节点与会话不变） |

## 四、字段约定（S1/S2 并行前冻结）

| 字段 | 位置 | 说明 |
| --- | --- | --- |
| `agentSessionFile` | `node.data` | 会话文件名，懒创建 |
| `agentSessionCloneFrom` | `node.data` | 待克隆的源会话；首次打开面板时消费掉 |
| `agentLastPrompt` | `node.data` | 最近一轮提问摘要，发送开始即写，rewind/delete 后校正 |
| `toonflowAgentNode` | 会话 jsonl 自定义条目 | 标记节点会话，供 `listAgentSessions` 过滤 |
| 状态表 | canvas 层 `provide` | `{ [nodeId]: "idle" \| "waiting" \| "thinking" \| "running" }`，不落盘 |

## 五、状态映射（事件 → 状态）

| 状态 | 触发 |
| --- | --- |
| 待开始 | 无会话，或会话里没有用户消息 |
| 等待输入 | 有会话且当前不在运行（含 `question` 待回答、被停止、失败——不新增第五态，摘要行追加「上轮失败/已停止：…」） |
| 理解中 | 已 accepted / 已下发 userMessage，尚未收到任何 assistant 活动（thinking / tool / text） |
| 运行中 | 收到任一 assistant 活动事件且流未结束；tool-first 的轮次直接进运行中，不进理解中 |

## 六、非目标

- 不做节点级模型/温度覆盖；不做上游变化自动运行的调度器；不做节点内嵌聊天；不做失败态标签；不把 Agent 节点做成 subagent；不承诺跨刷新/跨标签的运行重连。

## 八、验收标准

1. 加节点后磁盘上不产生 `.jsonl`；首次发送正好产生一个，并写入 `agentSessionFile`；重开画布能恢复。
2. 断开面板/点空白：运行中的一轮继续到结束，节点状态继续变；空闲时关闭并重开，消息完整。
3. 3 个上游 + 不手写 @：消息里出现 3 个引用 chip，服务端接受，令牌齐全；手动重复一次被去重。
4. 状态在事件后 100ms 内反映到节点；状态变化不触发画布保存。
5. 节点会话不出现在历史列表；旧会话与子会话照常可见。
6. 任意复制路径下两个节点会话文件不同；复制发生时源会话不被改动。
7. 删节点→撤销：对话完好；不撤销→撤销窗口过后文件被清理。
8. 面板内分支生成新 Agent 节点，原节点与其会话不变。
9. 面板几何：50% / 200% 缩放下贴边误差 ≤1px；越界自动翻到节点左侧。
