# 需求矩阵：图片裁剪增加上下翻转

- 时间：2026-11-13 16:08
- 模块：`packages/nodes/imageNode`（裁剪弹窗，图片生成节点共用）、`packages/nodes/imageGenerationNode`
- 状态：已实施

## 1. 需求背景

裁剪弹窗已经有「左右镜像」开关（`flipped`）：预览用 CSS 镜像，应用时按镜像换算源矩形重绘并落盘。用户希望再补一个上下镜像，两个轴独立可选。

## 2. 需求描述

裁剪弹窗的比例行里并排提供「左右」「上下」两个开关；两个可同时打开（等价 180°）。预览立即反映组合镜像；应用后落盘新图并替换输出；重开弹窗能还原上次的翻转组合。

## 3. 需求矩阵

| # | 描述 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | 新增「上下」开关，与「左右」独立，可同时开启 | P1 | 低 | 低 |
| R2 | 预览正确反映两个轴的组合（`scale(sx, sy)`） | P1 | 低 | 中（裁剪框/遮罩不参与镜像，需与原有左右行为一致） |
| R3 | 应用时重绘正确：源矩形按 y 换算 + 画布 transform 叠加 | P0 | 中 | 高（算错会裁错位置） |
| R4 | 翻转组合持久化到 `data.crop.last` 并在重开时还原 | P2 | 低 | 低（旧数据只有 flipped 要兼容） |
| R5 | 两个消费节点（图片 / 图片生成）的提示文案覆盖三种组合 | P2 | 低 | 低 |
| R6 | 整图 + 只有翻转时仍可应用（当作翻转工具） | P2 | 低 | 低 |

## 4. 非目标

- 不加 90°/270° 旋转（会改动裁剪框与整图坐标系换算，单独评估）。
- 不在节点卡片上加快捷翻转入口。
