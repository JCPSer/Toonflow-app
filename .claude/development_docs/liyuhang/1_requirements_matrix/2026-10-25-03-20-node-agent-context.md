# 需求矩阵：节点快捷加入 Agent 上下文

- 时间：2026-10-25 03:20
- 关联：素材库整改（同批交付）

## 一、背景

现在要把某个节点的输出交给右侧 agent 当上下文，必须打开输入框手动打 `@`、逐级选画布→节点→输出口。高频操作路径太长，且容易选错端口。

## 二、目标

在画布节点工具栏加一枚快捷按钮：点一下就把该节点的输出作为 `@` 提及插入右侧 agent 输入框，用户可继续补充文字再发送。

## 三、需求（R 编号）

| 编号 | 需求 | 说明 | 优先级 |
| --- | --- | --- | --- |
| N1 | 节点工具栏按钮 | 所有节点通用，位于节点顶部图标栏（与缩放/宫格切分同级），图标 + `aria-label="加入对话上下文"` | P0 |
| N2 | 单输出直接插入 | 节点只有一个有值输出时，点击即插入 `@节点名` 到输入框，不弹菜单 | P0 |
| N3 | 多输出弹选择 | 多个有值输出时，在按钮旁弹出端口列表（输出名 + 类型 + 缩略图），选一个插入；支持键盘上下 + Enter | P0 |
| N4 | 插入语义 | 复用现有 mention 机制（`AgentMention` + `{{mention:id}}`），与手动 `@` 完全等价；插入后输入框聚焦、光标在末尾 | P0 |
| N5 | 面板联动 | agent 面板未打开时自动打开并聚焦；面板被拖动/停靠时不影响 | P0 |
| N6 | 无输出反馈 | 节点没有任何有值输出时按钮禁用，`title` 说明「暂无输出」 | P1 |
| N7 | 上限与去重 | 沿用「每条消息最多 20 个提及」；已存在同一 output 时提示并不重复插入 | P1 |
| N8 | 不破坏现有交互 | 不改变 `@` 菜单、拖拽、画布快捷键；按钮点击不能触发节点选中拖动 | P0 |

## 四、明确不做

- 不做"一键发送"（用户已确认插入输入框即可）。
- 不把节点输出自动加入附件区。
- 不做批量把多个节点一次性加入（多选工具栏后续再说）。

## 五、风险

| 风险 | 处置 |
| --- | --- |
| 节点输出解析依赖画布实时状态 | 复用画布已有的 `selectCanvas` 客户端能力，不重新读盘 |
| 面板未挂载（例如在文档页） | 按钮只在画布页渲染，面板随工作区常驻 |
| 跨画布引用 | 只允许当前画布节点；与 mention 菜单的"当前画布"范围一致 |

## 六、评审意见

| 评审人 | 意见 | 结论 |
| --- | --- | --- |
| 用户 | 交互形态=插入输入框；位置=节点工具栏；多输出=弹选择 | 已采纳 |
