# 需求矩阵：画布空格预览选中节点

- 时间：2026-11-13 02:30
- 模块：画布（`apps/web/src/pages/workspace/panels/canvas/`）+ 快捷键定义
- 状态：已实施

## 1. 需求背景

节点在画布上是缩小展示的，图片/视频只有缩略区域，视频还要进节点内播放器才能看清。用户想要 Finder 式的「看一眼」：选中节点按空格，直接弹出大图或播放器，不用打开面板、不用改节点状态。

## 2. 需求描述

选中单个节点后**轻点空格**弹出预览：IMAGE/MASK 走大图查看器、VIDEO/AUDIO 走播放器弹窗。按住空格拖动仍是画布平移（空格原本就是平移键）。只响应单选；禁用节点也允许预览。

## 3. 需求矩阵

| # | 描述 | 优先级 | 难度 | 风险 |
| --- | --- | --- | --- | --- |
| R1 | 单选节点轻点空格预览主输出（视频 > 音频 > 图片/掩码） | P1 | 中 | 中（空格与平移冲突） |
| R2 | 按住空格拖动必须仍是平移，且松开后不能误弹预览 | P0 | 中 | 高（误伤核心手势） |
| R3 | 图片用可缩放查看器；视频/音频用播放器，且与全局播放互斥协调 | P1 | 低 | 低（已有 `installMediaPlayback`） |
| R4 | 多选、无选、弹窗/文本编辑/节点内控件、Agent 面板内不响应 | P1 | 低 | 低 |
| R5 | 预览打开时画布快捷键让位（含方向键、删除），Esc 仍能关闭 | P1 | 低 | 中（`el-image-viewer` 不是 `el-overlay`） |
| R6 | 快捷键可改、可关；与平移共用 Space 不被冲突校验误拦 | P2 | 低 | 低 |
| R7 | 切画布/失活时关闭预览，避免后台挂着播放器 | P2 | 低 | 低 |

## 4. 非目标

- 不做文本/提示词/参数预览（用户明确只预览媒体）。
- 不引入新的媒体解码或服务端接口，全部复用节点输出里已有的工作区 URL。
- 不改节点本身的缩略展示。
