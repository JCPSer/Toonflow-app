# 需求矩阵：画布单选节点按 Enter 重命名

- 时间：2026-11-07 13:57
- 提出人：liyuhang
- 状态：已实施（待人工验收）

## 1. 需求矩阵

| 项目 | 内容 |
| --- | --- |
| 背景 | 画布上点击节点只会选中，不会把焦点送进任何输入框；此时按 Enter 没有任何反馈。改名只能双击节点标题，或用右键菜单，手要移到标题上 |
| 目标 | 选中单个节点后直接按 Enter 进入标题编辑，行为对齐 macOS Finder 的 Return 改名 |
| 优先级 | P2（效率增强） |
| 难度 | 中：节点标题编辑在节点包 UMD 内部，宿主画布不能直接调用；需要新增跨包入口注册表，并重建全部节点包 |
| 风险 | 中：Enter 已被「清除未读提醒」占用；多选时改名对象不明确；重建全部节点 UMD 需同步应用数据目录 |

### R1 Enter 生效条件

- 恰好选中 1 个节点，且焦点不在输入框、按钮、可编辑区域、弹窗、Agent 面板内。
- 节点未禁用、非只读预览；分组节点同样生效。
- 多选时不响应（避免改名对象不明确）；空选时 Enter 仍归「清除未读提醒」。
- 输入法组合中（isComposing）不触发；按住重复只触发一次。

### R2 改名行为

- 进入标题编辑：标题变输入框并全选原文，行为与双击标题一致。
- Enter 确认、Esc 取消、失焦保存；空标题不写入。
- 改名进入撤销历史，⌘Z 可恢复。

### R3 绑定方式

- 写死 Enter，不进入「设置 → 画布快捷键」，避免与「清除未读提醒」出现同键冲突提示。
- 两者靠上下文互斥：有选区时 Enter 归重命名，无选区且焦点在空白处时归清除提醒。

### R4 覆盖范围

- 使用节点骨架（nodeSkeleton）的节点与画布分组节点。
- 应用数据目录中手工安装、非仓库构建的节点包不保证生效（它们需要各自重新构建）。

## 2. 验收标准

1. 点击单个生成节点（焦点不在输入框），按 Enter：标题进入编辑并全选。
2. 修改后 Enter 确认；⌘Z 恢复原名。
3. 按 Esc 取消编辑，名称不变。
4. 框选多个节点按 Enter：不进入改名。
5. 空选且焦点在画布空白处按 Enter：仍清除未读提醒。
6. 焦点在节点提示词输入框 / 设置弹窗 / Agent 面板内按 Enter：不进入改名。
7. 分组节点单选按 Enter：分组名进入编辑。
8. 禁用节点单选按 Enter：不进入改名。
