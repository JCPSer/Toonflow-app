# 需求矩阵：Agent 输入工具条布局 + Agent 提问横幅

- 记录时间：2026-10-29 13:30
- 负责人：liyuhang

## 一、需求背景

1. 用户截图反馈：画布 Agent 节点面板底部的输入工具条「太挤」——模型名被压到 0 宽后与右侧图标叠在一起（截图里文字与回形针重叠）。用户同时表示「语音按钮没有地方取消（我没找到）」。
2. Agent 节点用 `askUser` 向用户提问时，只有打开该节点的面板才能看到。用户关掉面板后无从得知，容易错过；多个节点同时提问时更没有入口。

## 二、需求矩阵

| 编号 | 需求描述 | 优先级 | 难度 | 风险 | 验收标准 |
| --- | --- | --- | --- | --- | --- |
| R1 | 工具条拥挤：加宽面板、模型名可省略、宽度不足时把低频按钮折叠进「⋯」 | P0 | 中 | 折叠逻辑在极窄/隐藏态误判会闪烁或卡在折叠态 | 任何面板宽度下 `senderActions.scrollWidth ≤ clientWidth`，无叠字；320px 最窄时允许折行但不溢出 |
| R2 | 语音输入开关搬到「设置 → 常规」，可从画布外侧发现并关闭 | P0 | 低 | 与旧位置（mediaGeneration 工具配置）双写冲突；旧配置含该键可能校验失败 | 常规设置里有关闭开关，关闭后按钮消失且长按手势失效，服务端 `general.voiceInputEnabled=false` |
| R3 | 任一 Agent 节点有未回答的 askUser 提问时，画布顶部出现提示，可点击跳转；多个合并渲染；激活该节点后自动消失 | P0 | 中高 | 事件接线断（emit 名不匹配）、提问结束不清除导致横幅残留、删节点后残留 | 提问时横幅出现；点一行打开对应节点面板并把视图带过去；打开后该行消失；回答/中断后不残留 |

## 三、边界与约束

- R1 不允许隐藏任何"不可替代"的能力：折叠进「⋯」后语音仍可触发，上下文用量仍可查看。
- R2 为单一真源：不在工具配置里再留一个开关，避免两处各写各的。工具 schema 保留字段仅为旧配置兼容（`z.strictObject`）。
- R3 只覆盖画布 Agent 节点；右侧浮动 Agent 面板不在本次范围（用户点名"agent 节点"）。
- R3 的"已读"语义 = 打开该节点面板；云端/后台无未读持久化，刷新后不保留。

## 四、评审意见（用户决策记录）

| 决策点 | 用户选择 | 结论 |
| --- | --- | --- |
| 拥挤方案 | 加宽 + 省略 + 溢出折叠 | 三项一起做 |
| 语音开关位置 | 搬到「设置 → 常规」 | 原「媒体生成控制」里的开关移除 |
| 提示位置 | 画布顶部居中横幅 | 多条目合并为列表 |
| 消失条件 | 打开即已读 | 未回答就关掉也不再弹；再次提问会重新出现 |
