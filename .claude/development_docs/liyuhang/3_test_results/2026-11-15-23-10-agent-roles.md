## 3. 待人工验收

- 在 Agent 节点面板头部「Agent 角色」新建「提示词审核员」，提示词写「只回答“通过”或“不通过”+一句理由」。
- 节点模型弹层选择该角色 → 发送任意提示词，回复应受角色约束。
- 切换角色后下一轮生效，历史不变；节点标题显示角色名。
- 删除该角色 → 节点选择器回退「通用」并提示，派发任务不再使用旧角色。
- 重启应用后角色仍在。

## 4. 已知边界

- 描述不进入提示词；角色不携带模型/思考强度；子 Agent 不继承角色；手动压缩不带角色。
- 角色名不强制唯一；会话 JSONL 暂不记录每轮角色 id（审计留待后续）。
- 角色保存复用 `/api/settings/save`，会顺带刷新模型列表与 MCP 运行时（频率低，可接受）。
