## 一、归一化算法对真实画布的验证

用 `bun` 直接跑 `normalizeNodesToGrid`（假 flow 对象，不改动真实文件）：

| 画布 | 归一化前错位数 | 归一化后错位数 | 组内间距最大变化 |
| --- | --- | --- | --- |
| 蕾姆Rem/1-早上起床-特殊唤醒服务 | 7 / 28 | 0 | 0px |
| 蕾姆Rem/4-教学楼天台的大胆行为 | 11 / 28 | 0 | 8px |
| 黒木/女人物换头 | 3 / 3 | 0 | 0px |

- 两个画布组内间距完全不变（整组各差 8px 的情形）；
- `4-教学楼天台` 有 8px 变化，来自其中某个 `- 副本` 节点的小数坐标（`968.5499504661576`），小数必须收敛，属预期；
- 环检测为新增防线，正常数据不触发。

## 二、源码写入点核对

| 写入点 | 处理 |
| --- | --- |
| `selectionNodes.fitGroupBounds` | 内边距 32/48 + `left/top` 吸附 |
| `selectionToolbar.groupNodes / mergeGroups / ungroupNodes / duplicateNodes` | 组位置、子节点绝对坐标、副本偏移全部吸附 |
| `selectionNodes.finishGroupDrag` | 吸附绝对坐标后减父组真实位置 |
| `arrangeSelection` | 居中结果逐个吸附 |
| `arrangeCanvas`（dagre 自动排版） | 结果逐个吸附 |
| `groupNode.finishResize` | 收手时吸附一次；未移动则跳过 |
| `index.createEmptyNode` | `center - 192` 且中心吸附 |
| `nodeSkeleton` 创建副本 | 按 `snapGrid` 吸附 |
| 粘贴 `pasteClipboardNode` | 锚点吸附（既有），根节点相对偏移继承源数据，由归一化兜底 |
| 节点包批量生成兄弟节点 | 不改，由下次打开画布归一化兜底（已写进方案） |
| 历史回放 `useCanvasHistory.restore` | 不吸附（正确，否则撤销失效） |

## 四、待人工验证（重启后）

1. 打开 `蕾姆Rem/1-早上起床-特殊唤醒服务`：原先 8px 偏移的分组与组内节点全部对齐；撤销可回到原样。
2. 新建分组 → 检查组与子节点绝对坐标 `% 16 === 0`。
3. 复制节点 / 分组 → 副本坐标是 16 的倍数。
4. 执行一次「整理画布」（dagre 自动排版）→ 全部节点仍在网格上。
5. 空画布拖入第一个节点 → 不再偏 8px。
6. 分组缩放手柄点一下不移动 → 尺寸不变；拖动后尺寸与位置为 16 的倍数，组内间距不变。
7. 关闭网格吸附后打开画布 → 坐标完全不变。

## 五、已知未覆盖

- 节点包内部批量生成兄弟节点（全景/宫格/变体/标记/视频音频动作/导演台/帧分析）不吸附，靠重开画布归一化。
