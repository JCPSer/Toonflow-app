## 四、批量加入素材库

| 场景 | 期望 | 实测 |
| --- | --- | --- |
| 选中 1 个有产物的图片节点 | 按钮可按 | 按钮存在且 `disabled=false` ✓ |
| 选中文本节点 | 按钮置灰 | `disabled=true` ✓ |
| 框选后工具栏按钮 | 出现在「解组」后 | `["水平排列","垂直排列","宫格排列","创建副本","打组","解组","加入素材库"]` ✓ |
| 端到端导入 | 文件落到 `<workspace>/library` | **未通过**：服务端返回「不能修改工作区根目录」 |

**端到端失败原因（已修）**：`importFileIntoLibrary` 里 `protectWorkspaceRoot(target.root, directory.path)` 在 `targetDir` 为空时必然成立（目标目录就是库根），导致任何「导入到素材库根目录」都被 400 拒绝——既影响本次批量入库，也影响既有的「保存到素材库」在根目录保存。已删掉该行（只保留对**文件路径**的保护），并直连模块验证：导入根目录成功、同名自动 `(2)`。
该修复需**重启桌面应用**后才在 HTTP 链路生效，重启后需再跑一次端到端确认。
