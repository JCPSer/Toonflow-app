## 3. 功能回归

| 用例 | 期望 | 实测 |
| --- | --- | --- |
| 画布图片节点显示 | 使用缩略图 | 视口内 15/15 张均为 `files/thumb?size=1024`，无 `blob:` |
| 节点宽度 | 按长宽比计算，不变 | 775×1024 缩略图与 1515×2002 原图比例一致，卡片宽度 182 px 未变 |
| 进入“标记” | 切到原图并等解码，画布按原图尺寸 | `<img>` 变为 blob 原图（1515×2002），`paintCanvas` = 1515×2002 |
| 退出“标记” | 回到缩略图、释放原图 | 退出后 `<img>` 回到 thumb，naturalWidth 775 |
| 下载 | 仍是原图 | `a[download]` 的 href 为 `blob:` 原图，文件名为原文件 |
| 全屏预览 | 原图 | `previewVisible && previewUrl` 分支未改，仍用原图 |
| 裁剪 / 缩放 / 宫格 / 打光 / 多角度 / 全景 | 原图 | 这些入口都继续绑定 `previewUrl`（未改） |
| 引用图卡片 | 缩略图展示，点开为原图 | 代码路径核对：卡片 `src` 用 256 缩略图，`previewSrcList` 用原图 |
| 缩略图失败 | 静默回退原图 | 代码路径核对：`onImageError` 先切回原图，不再弹“预览失败” |
| 动图 / svg / tiff | 保持原图 | `useThumbUrl` 只放行 png/jpg/jpeg/webp/bmp/avif |

## 5. 观察与遗留

- 首次打开画布仍有 10 次 >50 ms 帧（最大 463 ms），与页面初始化、54 个节点/插件实例挂载相关；改造前同口径为 10 次、最大 866 ms，本次略有改善但不是本次目标。
- 打开画布会对当前画布的图片输出串行预热缩略图（等上一张返回再发下一张，启动前先等 800 ms 让视口请求先排队）；服务端首次生成约 0.3 s/张，之后永久命中缓存。
- 画布视图位置会被自动保存：测试期间多次点击“适应视图”。测试结束后已把 `3-教室里的大胆行为.json` 的 `viewport` 还原为测试前的 `x=-1309.18, y=-330.375, zoom=1.05409`，并重启应用；备份在 `/Users/liyuhang/Downloads/AI临时目录/_perf/3-教室里的大胆行为.json.bak`。
- 历史记录弹窗、选中工具栏、自动保存、`backdrop-filter` 均未改动（分析中判为非主因或需要额外验证）。

## 6. 代码审查整改复验（第二轮）

| 问题 | 修法 | 复验 |
| --- | --- | --- |
| 进入编辑的等待期间被 `cancel()`/换图打断，可能出现"画布按原图、显示是缩略图"且无法保存 | `cancel()` 递增 `editToken`，等待原图解码后校验代次与 `editingSrc`，不匹配直接放弃 | 进入标记 → 原图 1515×2002 + 画布 1515×2002；退出 → 缩略图 775 |
| 图片已处于失败终态时 `waitImageLoad` 永不 resolve，`starting` 锁会把节点永久锁死 | `image.complete` 直接返回；监听 load/error 并加 10 s 超时 | 代码路径核对 |
| 缩略图失败且原图未就绪时切到空 `src`，第二次 error 会弹"无法预览该图片" | 记住失败的缩略图地址、`src` 为空时不 emit error、原图到达后不再重试同一坏地址 | 代码路径核对 |
| 展开聚合行的锚点只校正两帧，虚拟器自身的 ResizeObserver 校正可能覆盖 | 连续帧收敛（连续两帧稳定才收手，最多 8 帧），用 token 让新的展开取代旧的收敛 | 代码路径核对（真实会话中聚合行渲染正常） |
| 预热按 `mimeType` 过滤、与服务端扩展名判定不一致；预热不等返回，可能挤占视口请求 | 改扩展名白名单；`warmThumb` 返回 Promise 并按 URL 在途去重；预热串行 `await`，卸载时 token 失效 | 构建通过，缩略图全部命中 |
| 便签在"切画布"时可能丢失正在输入的正文 | 补 `nodeEvent.on("save", commitEdit)` | 代码路径核对 |
| 复制数据里的颜色未校验，可注入任意 CSS 值 | 只接受 `#rgb`/`#rrggbb` | 代码路径核对 |
| 工具摘要兜底显示任意字符串（可能泄露提示词/文件内容） | 只认 `action/path/query/command/name/url/file` | 代码路径核对 |
| 全部中断的聚合行显示"0 完成"且用成功色 | 单独的中断标题与 `data-status="interrupted"` 配色 | 代码路径核对 |
