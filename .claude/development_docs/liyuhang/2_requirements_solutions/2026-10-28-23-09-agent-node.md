## 二、S1：节点包

### 2.1 节点外观

```
┌─────────────────────────────┐
│ (icon) Agent1            ✎  │  titleBar（nodeSkeleton 自带）
├─────────────────────────────┤
│ ◐ 等待输入                   │  状态行：图标 + 文案，四种颜色
│                             │
│   添加技能给我任务            │  主区：有 agentLastPrompt 时显示摘要（2 行截断）
│                             │        否则显示虚线占位
│                             │
│ ⠿ 无输入                     │  尾部：上游摘要（"文本 120 字 / 图片"）或「无输入」
└─────────────────────────────┘
```

- 端口：只有左侧 `in`，`dataType: "*"`。
- 状态色：待开始/等待输入=次要文字色，理解中=主色 + 呼吸边框（复用 `nodeSkeleton` 的 `running`），运行中=主色实心点。
- 整卡可点击（宿主监听 `onNodeClick` 打开面板），节点内不放按钮，避免与拖拽冲突。

### 2.2 数据来源

```
useNode({ label: "Agent", icon, handles: [in], outputs: {} })
status = useAgentNodeStatus(id)            // inject 状态表，默认 "idle"
lastPrompt = node.data.agentLastPrompt     // 只读
inputSummary = useNodeEvent().on("input:in", values => 汇总端口与数量)
```

节点包不发起任何网络请求，不创建会话——会话归宿主管。

## 三、S2：画布层对话面板

### 3.1 挂载与几何

```
canvas/index.vue 模板：
    <vue-flow>…</vue-flow>
    <agentNodePanel />          ← 紧跟其后，继承 canvas 实例的 provide("canvas")
```

```
panelRect(node, viewport, container):
    left  = viewport.x + (node.computedPosition.x + node.dimensions.width) * zoom + 12
    top   = viewport.y + node.computedPosition.y * zoom
    if left + PANEL_W > container.width: left = viewport.x + node.computedPosition.x * zoom - PANEL_W - 12
    top  = clamp(top, 8, container.height - PANEL_H - 8)
```

- 固定像素宽 380、高 `min(560, container.height - 24)`，不随缩放变化。
- 依赖：`viewport` 响应式 + `node.computedPosition` / `node.dimensions` + 容器尺寸；用 `computed` 计算，不逐帧轮询。
- 层级 `z-index: 10`（高于 overlayHost 的 5 / 选择工具条的 6，低于 floatingPanel 的 1001）；`pointer-events: auto`；加 `nowheel`、`nopan` 类；扩展画布剪贴板排除白名单。
- 画布切到后台（`active=false`）或节点被删 → 面板隐藏。

### 3.2 打开 / 关闭 / 生命周期

```
onNodeClick(node):
    if node.type !== "remote-agentNode": closePanel(); return
    openPanel(node.id)

openPanel(id):
    entry = entries[id] ??= { visible: false, running: false, initial: null }
    if entry.initial == null: loadSession(id)        // GET /api/agent/get，404 → 视为空会话
    entry.visible = true; current = id

closePanel():
    entry = entries[current]
    entry.visible = false
    if !entry.running: entries.delete(current)        // 空闲才真正卸载
```

- `v-show` 控制可见性；运行中的实例保持挂载，流继续，状态继续写状态表。
- 关闭面板不触发任何 abort；只有工作区切换/画布实例卸载才中断。

### 3.3 会话字段

```
conversation @session(file)  → node.data.agentSessionFile = file; flushCanvasSave()
首次打开面板时：
    if node.data.agentSessionCloneFrom: POST /api/agent/clone → 得 file，清 cloneFrom，写回
    else if agentSessionFile 且 GET 404 → 提示「会话文件已丢失，已重新开始」，清字段
```

`agentLastPrompt`：新增 `conversation` 的 `promptStart` 事件（发送开始即发），面板写入 `node.data.agentLastPrompt`（`mentionPlainText` 后截 120 字）；rewind/delete 后由 `getAgentSession` 回填的最新用户消息校正。

### 3.4 状态表

```
canvas 层：
    const statuses = reactive<Record<string, AgentNodeStatus>>({})
    provide(AGENT_NODE_STATUS, statuses)

conversation 新增 status 事件：{ phase: "idle"|"waiting"|"thinking"|"running" }
    发出时机（在现有 sendMessage 状态机里插入）：
        accepted / userMessage 已下发        → thinking
        首个 thinking|tool|text 事件         → running
        done / error / 用户点停止            → waiting（error 时附带 lastError 文案）
        无会话 / 无用户消息                  → idle（面板初次加载时根据消息推断）
面板转发：statuses[nodeId] = phase
```

- 状态只写内存，不写 `node.data`，不触发画布保存。
- 节点包通过 `inject(AGENT_NODE_STATUS)` 读取，缺省 `idle`。

### 3.5 上游引用注入

```
conversation 新增 prop：extraMentions?: { id, label }[]
sendMessage 组装文本时：
    for m in extraMentions:
        if 文本里没有 `{{mention:m.id}}`: 追加 ` {{mention:m.id}}`
    请求体 mentions 合并去重，上限 20
```

面板侧生成：取 `getTargetSources(nodeId, "in", nodes, edges)` 的直接上游，按源节点 id 去重，标签用端口摘要；源值不可用的上游跳过。

### 3.6 面板内分支

```
「复制为新会话」→ POST /api/agent/fork（entryId = 最后一条用户消息）
    → 在画布上 newNode：type remote-agentNode，位置在源节点右下方 40/40
    → newNode.data.agentSessionFile = 返回的 file
```

原节点与会话不动。

## 四、S3：服务端

### 4.1 节点标记与历史过滤

```
run(options):
    打开/新建会话后：
        if options.nodeBinding 且首条标记不存在:
            appendCustomEntry("toonflowAgentNode", { canvasId, nodeId })

listAgentSessions(dir, { includeAgentNodes = false }):
    逐个候选文件，读前 8KB 查 `"toonflowAgentNode"`
    命中且 !includeAgentNodes → 跳过
```

- 旧文件不含标记，行为不变；子会话沿用 `parentSessionPath` 过滤。
- MCP 复用同一函数，默认同样看不到节点会话。

### 4.2 克隆

```
POST /api/agent/clone { directory, sessionFile }
    源文件必须存在且通过文件名正则
    读全文 → 新文件名（同命名规则）→ 逐行原样写入（id 在文件内唯一即可）
    末尾追加 session_info：「<原名> · 副本」
    返回 { file, name }
```

### 4.3 守卫删除

```
DELETE /api/agent/session { directory, sessionFile }
    if activeSessions 命中该文件 → 409「会话正在运行」
    else 删除文件（不存在视为成功）
```

节点删除走 `onNodesDropped` 清理链路（撤销窗口过后），失败只记日志，不阻断。
