## 1. 方案总览

新建独立节点插件包 `packages/nodes/noteNode`（类型 `remote-noteNode`，显示名“便签”），复用公共外壳 `nodeSkeleton`，不定义任何端口，正文与配色不调用任何模型。

三块核心实现（已由初审逐条核对源码）：

1. **正文**：`node.data.noteText`；双击正文进入编辑（受控 `textarea`，编辑期只改局部草稿，退出时一次写 `data`）。`textarea` 标签天然被 Vue Flow 的 `isInputDOMNode` 识别，画布的快捷键守卫据此放行，因此不必依赖 `keydown.stop`。
2. **尺寸**：`node.style.width/height`（Vue Flow 的 `getStyle` 会合并 `node.style` 并展开到 `.vue-flow__node` 外层）。四角手柄缩放，最小 160×160，`batchCanvasHistory` 包住整个拖拽使其只占一步撤销。
3. **配色**：`node.style` 的自定义属性 `--note-bg` / `--note-color`。`style` 属非运行态字段，变化会触发 `scheduleCanvasChange → record`，因此改色可 ⌘Z；正文在 `data` 里，`data` 只保存不入历史。

复制路径：`emit("copy")` 的 patch 只并入 `data`，但它覆盖了骨架菜单的复制节点/创建副本/复制到剪贴板，以及画布 ⌘C、拖拽复制、选择工具条“创建副本”等多条路径。因此把当前 `style` 以临时字段 `noteStyle` 塞进 `data`，新实例挂载时写回并删除——不改共享脚手架；画布 ⌘C 本来就带完整 `style`，`noteStyle` 对它冗余但无害。

## 3. 数据模型

```ts
// node.data
{ label: string, noteText: string, noteStyle?: string /* 仅复制传递的临时字段 */ }
// node.style（Vue Flow 应用到外层容器；落盘、进撤销快照）
{ width: "320px", height: "240px", "--note-bg": "#FFF5B8", "--note-color": "#1F1F1F" }
```

配色常量：

- 背景：黄 `#FFF5B8`（默认）、粉 `#FBD5E0`、蓝 `#CFE3FF`、绿 `#D5F0D3`、紫 `#E4D9F7`、灰 `#E9E9E9`
- 字色：黑 `#1F1F1F`（默认）、深灰 `#5C5C5C`、白 `#FFFFFF`、红 `#C0392B`、蓝 `#1A5FB4`、绿 `#2E7D32`

正文与卡片取色统一用 `var(--note-bg, #FFF5B8)` / `var(--note-color, #1F1F1F)`，这样快照里缺 `style` 的极端场景（旧画布、撤销到挂载前的快照）仍有兜底。

## 4. 交互与布局设计（UI）

### 4.1 节点外观

```
┌──────────────────────────────┐
│ ▣ 便签                ↻  🗑 │  ← nodeSkeleton 标题栏（细，可双击改名）
├──────────────────────────────┤

│                              │
└──────────────────────────────┘

```

- 隐藏 `el-card` 默认边框/阴影，改便签投影；标题栏文字色跟随 `--note-color`。
- 空正文显示占位“双击输入便签…”（正文色 45% 透明度）。
- 正文区 `padding: 10px 12px`，滚动条仅溢出时出现（宽度 ≤6px）。

### 4.2 浮动工具栏（选中时显示，替换 `#top` 默认内容）

```
[● ● ● ● ● ●] │ [A ▾]
 背景 6 色      字色下拉
```

- `topWidth="max-content"`，避免默认 `20vw` 在窄窗口压扁色板。
- 背景色块 18px 圆点，当前色带描边与对勾；点击写 `style["--note-bg"]`。
- 字色下拉：`el-dropdown` 列表项“色点 + 名称”。
- 色板自身显式设 `color`（深色文字），否则会继承 wrapper 上的 `--note-color`，用户选白字后色板不可读。
- 不保留骨架默认的“添加到素材库/加入对话/下载/全屏”；标题栏刷新、删除按钮保留。
- 显示条件是 `topVisible && slotsVisible`：单选可见；多选、框选或拖拽后会收起，需重新点选节点。

### 4.3 交互细节

| 交互 | 行为 |
| --- | --- |
| 单击节点 | 仅选中（骨架默认），可拖拽 |
| 双击正文 | 进入编辑，`textarea` 获焦、光标落末尾；`@dblclick.stop` 拦掉骨架 `focusNode`（双击缩放视口）与画布双击菜单 |
| 编辑中按键 | 用 `textarea` 本身（Vue Flow `isInputDOMNode` 识别），画布快捷键自然放行；Esc 提交退出，带 `isComposing` 守卫，且不冒泡 |
| 失焦 | 提交并退出 |
| 右键 | `textarea` 上 `@contextmenu.stop`，否则冒泡到骨架会打开节点菜单、挡掉原生复制粘贴 |
| 滚轮 | 展示层与编辑层都加 `nowheel`，否则画布 `panOnScroll` 会平移 |
| 拖拽 | 正文层与 `textarea` 加 `nodrag nopan`，否则点击会被拖拽层 `preventDefault`，焦点/选字不可靠 |
| 缩放手柄 | 选中时显示；拖拽实时改 `style`/`dimensions`，收手吸附网格；最小 160×160；`batchCanvasHistory` 记一步 |
| 组内缩放 | 允许超出组框；组在下一次拖动/整理时由 `fitGroupBounds` 贴合（节点包无法直接调用画布侧方法） |
| 复制/粘贴 | 通过 `noteStyle` 携带尺寸与配色，挂载写回；解析失败则忽略，不阻断挂载 |

## 5. 关键实现要点（伪代码）

```
defineOptions({ inheritAttrs: false, icon: IconNote })
const { node } = useNode({ label: "便签" })          // 无 handles、无 outputs
const data = node.data as { noteText?: string; noteStyle?: string }

// copy 事件必须在 setup 里注册（依赖 onScopeDispose）
nodeEvent.on("copy", () => ({ noteStyle: JSON.stringify(styleOf(node)) }))

onMounted:
    applyStyleDefaults():          // 新建节点只有 data.label，没有 style
        if (!style.width)      → width "320px"
        if (!style.height)     → height "240px"
        if (!style["--note-bg"])   → 默认黄
        if (!style["--note-color"])→ 默认黑
    if (data.noteStyle) {
        try { patch = JSON.parse(data.noteStyle); 校验 width/height/颜色均为字符串后合并 } catch {}
        delete data.noteStyle
    }

watch(() => [styleOf(node).width, styleOf(node).height], () => {
    // 撤销到“没有 style 的快照”时兜底，避免节点塌成骨架默认尺寸
    if (!styleOf(node).width || !styleOf(node).height) applyStyleDefaults()
}, { flush: "post" })

function setStyle(patch):      // 合并，不整体替换，避免丢 width/height 与另一枚颜色
    node.style = { ...styleOf(node), ...patch }        // 触发 record（一步撤销）

编辑（草稿制）：
    startEdit():  editing = true; draft = data.noteText ?? ""; nextTick → textarea.focus() + 光标末尾
    commitEdit(): if (draft !== data.noteText) data.noteText = draft; editing = false

缩放（照搬 groupNode 的完整机制，去掉子节点补偿，补组内坐标换算）：
    startResize → batchHistory(action) → node.resizing = true; setPointerCapture
    moveResize  → width = max(160, w + dx*corner.x); height = max(160, h + dy*corner.y)
                  style 合并写 width/height；node.dimensions 同步
    finishResize→ 未移动则跳过；收手吸附一次：
                  if (parentNode) 用 parent.computedPosition + position 换算绝对坐标吸附，再减回父组坐标
                  （参考 selectionNodes.ts:179-181，直接 snap 相对坐标会让节点永久偏离网格）
```

布局：

- 骨架宽度用**内联 style** 覆盖（`<nodeSkeleton style="width:100%;height:100%">`），不用 `:deep` 抢 220px 的优先级（选择器同权重，顺序不可控）。
- 卡片高度链：`.nodeSkeleton` 纵向 flex → `.cardContainer { flex:1; min-height:0 }` → `.contentCard` 与 `.el-card__body { height:100% }`，`body` 的默认 `padding:8px` 用 `!important` 归零，自管内边距。
- 缩放手柄放在 `.cardContainer` 的绝对定位覆盖层（不放进会滚动、会随编辑态卸载的正文层），`v-if` 不随编辑态变化，避免拖动中被卸载丢 `pointerCapture`。

## 6. 边界与风险

| 风险 | 说明 | 处理 |
| --- | --- | --- |
| 骨架固定 220px 宽 | `nodeSkeleton.vue:711` | 内联 `width/height:100%` |
| 卡片最小高度 | 100px（`nodeSkeleton.vue:282`）+ 标题栏约 32px | 最小高度 160，不覆盖内联 `min-height` |
| 缩放刷撤销栈 | `style` 变化每帧 record，101 步上限 | `batchCanvasHistory` 包住 pointerdown→pointerup |
| 双击抢焦点/缩放视口 | 骨架根 `@dblclick.stop="focusNode"` | 正文 `@dblclick.stop` |
| 拖拽层吃焦点 | 未命中 `.nodrag` 时 d3-drag `preventDefault` | 正文与 `textarea` 加 `nodrag nopan` |
| 滚轮平移画布 | `panOnScroll` 为 true | 展示层与编辑层都加 `nowheel` |
| 快捷键 | 画布在 window 捕获阶段监听，`keydown.stop` 挡不住 | 依赖 `textarea` 被 `isInputDOMNode` 识别；用原生 `textarea`，不用 contenteditable |
| 复制丢样式 | 骨架复制只带 `data` | `noteStyle` 临时字段 + 挂载写回 + 解析兜底 |
| 组内吸附偏移 | 子节点 `position` 是相对父组坐标 | 吸附前换算绝对坐标，再减回 |
| 组内缩放溢出 | `fitGroupBounds` 不由尺寸变化触发 | 明确允许溢出，下次组操作贴合 |
| 撤销到无 style 快照 | `restoreFields` 会整体替换并删除缺失键 | CSS 变量兜底 + `watch` 补默认尺寸 |
| 编辑保存开销 | `data` 深监听会防抖保存整张画布 | 草稿制，退出时一次写入 |
| 暗色主题 | 便签固定色板 | 不随主题，白字由用户自选 |
